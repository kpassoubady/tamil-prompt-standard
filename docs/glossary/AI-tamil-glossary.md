# தமிழ் AI கலைச்சொற்கள் — பதிப்பு 2 (Tamil AI Glossary — Version 2)

குறிப்பு: கலைச்சொற்கள் இயன்றவரை ஒருமை வடிவில் தரப்படுகின்றன; தேவையான இடங்களில் தமிழின் இயல்பான பன்மை விகுதி (-கள்) சேர்த்துப் பயன்படுத்தலாம்.

| English | Primary Tamil Word | Alternative Tamil Words | Notes / Explanation |
| --- | --- | --- | --- |
| Abductive Reasoning | ஊக ஏரணம் | — | அரைகுறைத் தரவிலிருந்து சிறந்த காரணத்தை ஊகிக்கும் ஏரண முறை. |
| Abstraction | புறவயமாக்கம் | — | விவரங்களை மறைத்துப் பொதுக் கருத்தை அல்லது இடைமுகத்தை மட்டும் வெளிக்காட்டுதல்; கணினியியலின் அடிப்படைக் கருத்துகளில் ஒன்று. |
| Activation Function | தூண்டல் சார்பு | இயக்கச்சார்பு | நரம்புவலையில் ஒரு கணுவுக்குக் கிடைக்கும் மதிப்பை மாற்றி அடுத்த அடுக்கு பயன்படுத்தும் சார்பு (உ-ம்: ReLU, Sigmoid). |
| Adapter | இணைப்புத் தொகுதி | ஏற்பி | PEFT முறையில் சிறிய அளவு கூடுதல் எடைகளை மட்டும் சேர்த்து நுண்திருத்தம் செய்யும் கூறு. |
| Adversarial Attack | எதிரிடைத் தாக்குதல் | — | AI-ஐ ஏமாற்ற உள்ளீட்டில் நுட்பமான மாற்றங்கள் செய்யும் தாக்குதல் முறை. |
| Affective AI |உணர்வியலறிவு  | உணர்வுசார் செய்யறிவு | மனித உணர்வுகளை அறிந்து கொள்ளும், புரிந்து கொள்ளும், மற்றும் தகுந்த வகையில் பதிலளிக்கும் திறன் கொண்ட AI மாதிரிகள். |
| Affective Computing | உணர்வுசார் கணினியியல் | — | மனித உணர்வுகளை அறிய, பகுப்பாய்வு செய்ய, மற்றும் இணைக்க உதவும் கணினியியல் துறை. |
| Agent | செயற்பாட்டாலி | செயல்முகவர் / மாற்றுச்செயலி | இலக்கு நோக்கித் தானாகவே இயங்கும், முடிவெடுக்கும், மற்றும் கருவிகளைப் பயன்படுத்தும் மென்பொருள். (குறிப்பு: 'ஆலி' விகுதி செயலி, கணினி போன்று non-human/machine entity-ஐக் குறிக்கிறது; 'முகவர்' மரபில் மனிதப் பிரதிநிதியைக் குறிப்பதால் AI context-ல் 'செயற்பாட்டாலி' மிகப் பொருத்தம்.) |
| Agent Orchestration | செயற்பாட்டாலி ஒருங்கிணைப்பு | செயல்முகவர் ஒருங்கிணைப்பு / முகவர் அணிவகுப்பு | பல செயற்பாட்டாலிகள் செய்திபரிமாறி ஒருங்கிணைந்து சிக்கலான வேலையை முடிக்கும் கட்டமைப்பு. |
| Agentic AI | செயலூக்கச் செய்யறிவு | — | தானே முடிவெடுத்துக் கருவிகளைப் பயன்படுத்தி இலக்கு நோக்கித் தொடர்ச்சியாகச் செயல்படும் AI மாதிரி. |
| AI Agent | செய்யறிவுச் செயற்பாட்டாலி | செய்யறிவு முகவர் | சூழலைப் புரிந்து, முடிவெடுத்து, கருவிகளைப் பயன்படுத்தித் தானாகச் செயல்படும் தன்னாட்சி நிரல். |
| AI Chatbot | செய்யுரையினி | — | செய் (செய்யறிவு) + உரை (உரையாடல்) + இனி (கருவி விகுதி). பயனருடன் இயல்பாக உரையாடும் மென்பொருள். |
| AI Copilot | செய்யறிவுத் துணைவன் | துணையியக்கி | நிரலெழுதுதல், எழுதுதல் அல்லது வடிவமைப்பு போன்ற பணிகளில் மனிதருக்குத் துணையாக இருந்து ஆலோசனைகளையும் குறியீடுகளையும் வழங்கும் AI மென்பொருள். |
| AI Governance | செய்யறிவு ஆளுகை | — | AI வடிவமைப்பு, பயன்பாடு, பொறுப்புணர்வைச் சட்டம் மற்றும் கொள்கை வழிநடத்தும் கட்டமைப்பு. |
| AI Safety | செய்யறிவுப் பாதுகாப்பு | — | AI அமைப்புகள் மனிதர்களுக்குத் தீங்கு விளைவிக்காமல், எதிர்பாராத ஆபத்துகளை உருவாக்காமல் பாதுகாப்பாகச் செயல்படுவதை உறுதிசெய்யும் ஆராய்ச்சித் துறை. |
| AI Sandbox | செய்யறிவுப் பரிசோதனைக்களம் | செய்யறிவு ஆய்விடம் | AI மாதிரிகளைப் பாதுகாப்பான, தனிமைப்படுத்தப்பட்ட சூழலில் சோதனை செய்யவும் மேம்படுத்தவும் பயன்படும் கட்டமைப்பு. |
| Algorithm | நெறிமுறை | — | ஒரு வேலையைச் செய்ய அல்லது சிக்கலைத் தீர்க்கத் தேவையான துல்லியமான படிநிலை வரிசை. |
| Alignment | நெறிசீரமைப்பு | மதிப்புச் சீரமைப்பு | AI மாதிரியின் செயல்பாடுகள் மனித மதிப்புகள், உண்மைகள் மற்றும் பாதுகாப்பு விதிகளுக்கு உட்பட்டு இருப்பதை உறுதிசெய்யும் செயல்முறை. |
| Analyze | பகுப்பாய்வு | — | ஒரு தரவையோ அல்லது சிக்கலையோ அதன் அடிப்படை கூறுகளாகப் பிரித்து ஆழமாக ஆராயும் செயல். |
| Annotated Datasets | அடையாளமிட்ட தரவுக்கணங்கள் | குறியிட்ட தரவுக்கணங்கள் | இயந்திரக் கற்றலுக்குப் பயன்படும் வகையில், மனிதர்களால் அல்லது நிரல்களால் விளக்கங்கள் அல்லது லேபிள்கள் இணைக்கப்பட்ட தரவுகளின் தொகுப்பு. |
| Annotation Schema | தரவுக் குறியீட்டு வரைவு | குறியீட்டுத் திட்டம் | தரவுக் கணத்தில் ஒவ்வொரு தரவுப் பகுதிக்கும் எத்தகைய பெயரிடல் அல்லது குறியீடு பயன்படுத்தப்பட வேண்டும் என்பதை வரையறுக்கும் கட்டமைப்பு. |
| Anomaly Detection | வழுக்கண்டறிதல் | இயல்பு விலகல் கண்டறிதல் | வழு = anomaly. சாதாரண தரவு வடிவத்திலிருந்து விலகிய அல்லது இயல்புக்கு மாறான தரவுப்புள்ளிகளை அடையாளம் காணும் நுட்பம். |
| API | செயலி நிரலாக்க இடைமுகம் | — | ஒரு செயலி மற்றொரு செயலியுடன் தொடர்பு கொள்ளப் பயன்படும் கட்டமைப்பு (Application Programming Interface). |
| App | குறுஞ்செயலி | செயலி | குறிப்பிட்ட ஒரு சிறு பணிக்காக வடிவமைக்கப்பட்ட மென்பொருள். |
| Application | செயலி | — | ஒரு குறிப்பிட்ட பயனர் தேவையை நிறைவேற்றப் பயன்படும் முழுமையான மென்பொருள் கட்டமைப்பு. |
| Artificial General Intelligence (AGI) | செய்சாலறிவு | பொதுச் செய்யறிவு | செய் + சால் + அறிவு. மனிதனைப் போல எந்தத் துறையிலும் பொதுவாகச் சிந்திக்கவும், கற்கவும், சிக்கல் தீர்க்கவும் வல்ல AI நிலை. |
| Artificial Intelligence (AI) | செய்யறிவு | செயற்கை நுண்ணறிவு | 'செய்' (artificial) + 'அறிவு' (intelligence). மனித அறிவைப் போலச் செயல்படும் திறன் கொண்ட கணினி அமைப்புகள். |
| Artificial Neural Networks (ANN) | செய்நரவலை | — | மனித மூளையின் நரம்பணு அமைப்பைப் பின்பற்றி வடிவமைக்கப்பட்ட கணினி கட்டமைப்பு. |
| Artificial Super Intelligence (ASI) | செய்வியனறிவு | — | செய் + வியன் + அறிவு. ஒட்டுமொத்த மனித அறிவையும் தாண்டிய திறமைகளைக் கொண்ட கற்பனை AI நிலை. |
| Asynchronous | தன்னேர் | ஒத்திசையா | ஒரே நேரத்தில் நடக்காமல், ஒரு செயல் முடிவதற்குள் மற்றொன்று தொடங்கும் முறை (எ-கா: தன்னேர் தரவுப் பரிமாற்றம்). |
| Attention | கவனம் | கவனிப்பு | உள்ளீட்டின் எந்தப் பகுதி மீது மாதிரி முக்கியமாகக் கவனம் செலுத்த வேண்டும் என்பதைத் தீர்மானிக்கும் நரவலை வழிமுறை. |
| Autoencoder | தான்குறியாக்கி | தான்சுருக்கி | உள்ளீட்டைச் சுருக்கி மீண்டும் மீட்டமைக்கும் நரவலை. |
| Autonomous Agent | தன்னாட்சிச் செயற்பாட்டாலி | தன்னாட்சி முகவர் / தன்னிச்சைச் செயலி | மனிதத் தலையீடின்றித் தானாகவே இயங்கும், முடிவெடுக்கும் செயற்பாட்டாலி. |
| Autonomous Workflow | தன்னாட்சிப் பணிப்பாய்வு | தன்னிச்சைப் பணித்தொடர் | மனிதத் தலையீடின்றி, பல படிநிலைகளைக் கொண்ட சிக்கலான பணிகளை AI தாமாகவே திட்டமிட்டுச் செயல்படுத்தும் தொடர்முறை. |
| Autoregressive Model | தன்னிழைவுத் தொடர் முறை | முன்னிலையடிப்படை முறை | முந்தைய சொற்களை வைத்து அடுத்த சொல் கணிக்கும் முறை (GPT போன்ற LLM-கள் இதன் அடிப்படையில் இயங்குகின்றன). |
| Backpropagation (of error) | பின்னோக்கிய பிழைப்பாய்ச்சம் | — | நரவலையில் பிழைகளைக் கணக்கிட்டு, எடைகளைச் (weights) சரிசெய்யப் பின்னோக்கிச் செல்லும் கணித முறை. |
| Backpropagation Neural Networks | பின்னோக்கிய பிழைப்பாய்ச்ச நரவலை | — | பின்னோக்கிய பிழைப்பாய்ச்ச முறையைப் பயன்படுத்திப் பயிற்றுவிக்கப்படும் நரவலைக் கட்டமைப்பு. |
| Batch Size | தொகுதி அளவு | — | ஒரு பயிற்சிச் சுழற்சியில் ஒரே நேரத்தில் பயன்படுத்தும் எடுத்துக்காட்டுகளின் எண்ணிக்கை. |
| Beam Search | கதிர் தேடல் | — | பல சாத்தியமான உரைத் தொடர்களை ஒருசேர வைத்துச் சிறந்ததைத் தேர்வுசெய்யும் தேடல் முறை. |
| Beam Width | கதிர் அகலம் | தேடல் அகலம் | கதிர் தேடலில் ஒரே நேரத்தில் நினைவில் கொள்ளும் சிறந்த தொடர்களின் (Sequences) எண்ணிக்கை. |
| Benchmark | அளவுகோல் | தரப்படுத்தல் | வெவ்வேறு AI மாதிரிகளின் செயல்திறனை ஒப்பிட்டு மதிப்பிடப் பயன்படுத்தப்படும் தரப்படுத்தப்பட்ட சோதனைகள் மற்றும் தரவுக் கணங்கள் (எ.கா: MMLU, HumanEval). |
| Bias | சாய்வு | பாரபட்சம் | பால், இனம் போன்றவற்றின் அடிப்படையில் AI வெளியீட்டில் ஏற்படும் பாரபட்சம்; பயிற்சித் தரவுக் குறைபாட்டால் உருவாவது. |
| Blockchain | கட்டச்சங்கிலி | — | தரவுகளை மாற்ற முடியாதபடி சங்கிலித் தொடராகத் தொகுத்துச் சேமிக்கும் பரவலாக்கப்பட்ட தரவுத்தளத் தொழில்நுட்பம். |
| Callback | கூவிளி | — | ஒரு செயல் முடிந்த பிறகு தானாகவே இயக்கப்படும்படி முன்கூட்டியே அனுப்பப்படும் சார்பு (Function). |
| Catastrophic Forgetting | பேரழிவு மறதி | — | புதிய தரவில் நுண்திருத்தம் செய்யும்போது மாதிரி பழைய அறிவை இழக்கும் நிலை. |
| Causal Language Model | காரணிய மொழி மாதிரி | — | இடமிருந்து வலமாக அடுத்த சொல்லைக் கணிக்கும் மாதிரி (GPT); MLM-க்கு எதிர்மாறானது. |
| Chain of Thought (CoT) | சிந்தனைச் சங்கிலி முறை | படிநிலைச் சிந்தனை | AI மாதிரியானது விடையை ஒரே அடியாகக் கூறாமல், மனிதனைப் போலப் படிப்படியாகக் காரண காரியங்களை விளக்கி விடை காணும் முறை. |
| ChatGPT | சாட்ஜிபிடி | — | ஓபன்ஏஐ (OpenAI) நிறுவனம் உருவாக்கிய, இயல்பான மொழியில் உரையாடும் பெருமொழி மாதிரி (LLM). |
| Chunking | உரைத்துண்டாக்கம் | பகுதிப் பகுப்பாகப் பிரித்தல் | நீண்ட ஆவணத்தை AI புரிந்துகொள்ளச் சிறிய பகுதிகளாக உடைக்கும் செயல்முறை. |
| Classification | வகைப்பாடு | — | தரவை முன்கூட்டியே தீர்மானிக்கப்பட்ட வகைகளில் ஒன்றில் சேர்த்தல். |
| Cloud Computing | முகில் கணிமை | மேகக் கணிமை | இணையத்தின் வழியே சேவையகங்கள் (Servers), தரவுத்தளங்கள் மற்றும் மென்பொருள்களைப் பயன்படுத்தும் தொழில்நுட்பம். |
| Clustering | கொத்தாக்கம் | — | ஒத்த பண்புகளைக் கொண்ட தரவுகளைக் குழுக்களாகப் பிரித்தல். |
| Code | நிரல் | — | கணினிக்குக் கட்டளைகளை வழங்கப் பயன்படுத்தப்படும் நிரலாக்க மொழித் தொடர்கள். |
| Compress | சுருக்கம் | தரவுச் சுருக்கம் | தரவின் அளவைக் குறைத்து, சேமிப்பக இடத்தையோ அலைவரிசையையோ மிச்சப்படுத்தும் செயல்முறை. |
| Computational Language Model | கணிய மொழியொப்பாக்கம் | கணிய மொழி மாதிரி | மொழியின் கட்டமைப்பைக் கணக்கீட்டு முறையில் வடிவமைத்துச் செயல்படும் மாதிரி. |
| Connectionism | கூட்டியியக்கியம் | — | மூளையின் நரம்பணு வலைப்பின்னலைப் போலக் கணினி அமைப்புகளையும் ஒன்றோடொன்று இணைத்துச் செயல்பட வைக்கும் அணுகுமுறை. |
| Constitutional AI | அடிப்படை விதிச் செய்யறிவு | அரசியல் சட்டச் செய்யறிவு | AI மாதிரிக்கு ஒரு "அடிப்படை விதி" அல்லது நெறிமுறை வழிகாட்டுதலை அளித்து, அதன் வெளியீடுகள் அந்த விதிகளுக்கு ஏற்ப இருக்கப் பயிற்றுவிக்கும் முறை (Anthropic நிறுவனத்தின் கட்டமைப்பு). |
| Context Window | சூழல் சாளரம் | உள்ளீட்டு வரம்பு / சூழல் நீளம் | ஒரு AI மாதிரி ஒரே நேரத்தில் படித்து நினைவில் கொள்ளக்கூடிய ஒட்டுமொத்த சொல்துண்டுகளின் (Tokens) அதிகபட்ச அளவு. |
| Contextual Embedding | சூழல் பொதிவு | — | வாக்கியச் சூழலைப் பொறுத்து மாறும் சொல் திசையன்; நிலையான பொதிவுகளுக்கு (Word2Vec) மாறாக BERT, GPT பயன்படுத்துவது. |
| Contrastive Learning | எதிர்வைப்புக் கற்றல் | ஒப்பீட்டுக் கற்றல் | ஒத்த ஜோடிகளை நெருக்கி, மாறுபட்டவற்றை விலக்கிக் கற்கும் முறை (CLIP). |
| Coreference Resolution | சுட்டுப்பெயர் இணைப்பு | பரிமாற்றுச் சுட்டுத்தீர்வு | 'அவன்', 'அது' போன்ற சுட்டுச்சொற்கள் எந்தப் பெயர்ச்சொல்லைக் குறிக்கின்றன என்று கண்டறியும் NLP நுட்பம். |
| Corpus | உரைத்தொகுப்பு | சொற்கிடங்கு | மொழி மாதிரிகளைப் பயிற்றுவிக்கப் பயன்படும் பெரிய உரைத் தரவுத் தொகுப்பு. |
| Cosine Similarity | கோண ஒப்புமை | கொசைன் ஒப்புமை | இரு திசையன்களுக்கு இடையிலான கோணத்தை வைத்து ஒப்புமையை அளவிடும் கணிதம்; RAG/தேடலின் அடிப்படை. |
| Critical Thinking Question | கிடுகறி வினா | திறன்நோக்கு வினா | கிடுகு (Critical) + அறி (Thinking) + வினா. ஆழமாகச் சிந்தித்துப் பகுப்பாய்வு செய்து விடையளிக்கும் வகையிலான கேள்வி. |
| Cross-Entropy | வகைப்புப் பிழை அளவு | குறுக்கு-எண்ட்ரோபி | கணிக்கப்பட்ட விநியோகத்துக்கும் உண்மை விநியோகத்துக்கும் இடையிலான வேறுபாடு; வகைப்பாட்டு இழப்புச் சார்பாகப் (Classification Loss Function) பயன்படுகிறது. |
| Culturally-aware AI | பண்பாட்டுணர்வுச் செய்யறிவு | பண்பாட்டுச் சார்பு செய்யறிவு | ஒரு குறிப்பிட்ட பண்பாட்டின் மரபுகள், மொழி, மதிப்புகள் மற்றும் சூழமைவை உணர்ந்து செயல்படும் AI மாதிரி. |
| Data Augmentation | தரவு விரிவாக்கம் | — | ஏற்கனவே உள்ள பயிற்சித் தரவுகளிலிருந்து புதிய, மாறுபட்ட எடுத்துக்காட்டுகளைச் செயற்கையாக உருவாக்கிப் பயிற்சித் தரவின் அளவை அதிகரிக்கும் நுட்பம். |
| Data Centre | தரவு மையம் | தரவு நடுவம் | கணினி அமைப்புகளையும், தொடர்புடைய தரவுச் சேமிப்பகங்களையும் ஒருங்கே மையப்படுத்தி நிர்வகிக்கும் கட்டமைப்பு. |
| Data Modeling | தரவு மாதிரியாக்கம் | — | ஒரு உண்மை உலகப் பிரச்சினையை அல்லது செயல்முறையைக் கணினி புரிந்துகொள்ளக்கூடிய தரவுக் கட்டமைப்பாக மாற்றும் முறை. |
| Data Points | தரவுப்புள்ளிகள் | — | ஒரு தரவுக் கணத்தில் உள்ள தனிப்பட்ட அளவீடுகள் அல்லது அவதானிப்புகள்; AI மாதிரிகள் இவற்றிலிருந்து கற்றுக்கொள்கின்றன. |
| Debugging | பிழைத்திருத்தம் | — | மென்பொருள் நிரலில் உள்ள தவறுகளைக் கண்டறிந்து சரிசெய்தல். |
| Decoder | குறிநீக்கி  | மீள்வடிவாக்கி | குறியாக்கப்பட்ட தரவிலிருந்து மனிதர்கள் அல்லது கணினி புரிந்துகொள்ளும் வெளியீட்டை உருவாக்கும் பகுதி. |
| Deductive Reasoning | பகுப்பு ஏரணம் | — | பொது விதிகளிலிருந்து குறிப்பிட்ட முடிவை எடுக்கும் தர்க்க முறை (எ.கா: அனைவரும் இறப்பர் → சாக்ரடீஸ் இறப்பார்). |
| Deep Learning | ஆழ்திறன் கற்றல் | ஆழ் கற்றல் | பல அடுக்கு நரவலைகளைப் பயன்படுத்திப் பெருமளவு தரவுகளிலிருந்து சிக்கலான அமைப்புகளைக் கற்றுக்கொள்ளும் முறை. |
| DeepFake | ஆழ்பொய் | — | AI நுட்பத்தைப் பயன்படுத்தி உருவாக்கப்படும் போலி காணொளி, படம் அல்லது ஒலி; அசலிலிருந்து வேறுபடுத்திப் பார்ப்பது கடினம். |
| DeepSeek (company) | ஆழ்தேடி | ஆழ்தேடல் | சீனாவில் தோன்றிய திறந்த மூல AI நிறுவனம்; ஆழ்ந்த தேடல்/ஆய்வு என்ற கருத்தை அடிப்படையாகக் கொண்டது. |
| DeepThink | ஆழ்சிந்தனை | — | Chain-of-Thought போன்ற, AI மாதிரி படிப்படியாக ஆழ்ந்து சிந்திக்கும் பகுத்தறிவு முறைகளுக்குப் பொதுச் சொல். |
| Dense Layer | அடர்த்தி அடுக்கு | — | ஒரு நரவலையில் முந்தைய அடுக்கின் அனைத்து நரம்பணுக்களுடனும் முழுமையாக இணைக்கப்பட்ட அடுக்கு. |
| Dense Model | அடர்த்தி மாதிரி | — | நரவலையில் உள்ள அனைத்து நரம்பணுக்களும் ஒன்றுக்கொன்று முழுமையாக இணைக்கப்பட்டு, அனைத்து எடைகளும் (Weights) செயல்படும் நிலையில் உள்ள மாதிரி (அரிது மாதிரிக்கு எதிர்மாறானது). |
| Deterministic Output | திட்டவட்ட வெளியீடு | உறுதியான வெளியீடு | ஒரே உள்ளீட்டை எத்தனை முறை கொடுத்தாலும், எவ்வித மாறுபாடும் இன்றி ஒவ்வொரு முறையும் AI ஒரே மாதிரியான முடிவைத் தரும் தன்மை (Temperature 0 ஆக இருக்கும் நிலை). |
| Deterministic Reasoning | திட்டவட்ட ஏரணம் | — | மாறாத கணித விதிகளின்படி, ஒவ்வொரு முறையும் ஒரே துல்லியமான முடிவைத் தரும் தர்க்க முறை. |
| Diffusion Model | விரவல் மாதிரி | பரவல் மாதிரி | இரைச்சலைச் (Noise) சேர்த்துப் பின் அதை நீக்குவதன் மூலம் தரவுகளிலிருந்து புதிய படங்களையோ ஒலிகளையோ உருவாக்கும் இயற்றறிவு மாதிரி. |
| Direct Preference Optimization (DPO) | நேரடி விருப்ப உகப்பாக்கம் | — | தனி ஒரு வெகுமதி மாதிரி (Reward Model) இல்லாமல், மனித விருப்பத் தரவுகளிலிருந்து நேரடியாக மாதிரியைச் செப்பனிடும் எளிய முறை. |
| Distillation | சுரக்காய்வு | அறிவுச் சுருக்கம் | பெரிய "ஆசிரிய" மாதிரியிலிருந்து (Teacher Model) அதன் அறிவைச் சிறிய "மாணவ" மாதிரிக்கு (Student Model) பரிமாற்றும் மாதிரிச் சுருக்க நுட்பம். |

| Documentation | ஆவணவாக்கம் | விளக்கக் குறிப்புகள் | மென்பொருள் அல்லது மாதிரியின் வடிவமைப்பு, பயன்பாடு மற்றும் குறியீடுகளை விளக்கும் விரிவான எழுத்துப்பூர்வப் பதிவு. |
| Dropout | துளைவிடல் | — | பயிற்சியில் சில நரம்புகளைத் தற்காலிகமாக முடக்கி மிகைப்பொருத்தத்தைக் (Overfitting) குறைக்கும் சீரமைப்பு (Regularization) நுட்பம். |
| Edge AI | விளிம்புநிலைச் செய்யறிவு | கருவிநிலைச் செய்யறிவு | கிளவுட் சேவையகங்களில் அல்லாமல், பயனரின் சாதனத்திலேயே (மொபைல், IoT கருவி) நேரடியாக இயங்கும் AI மாதிரி. |
| Edit | தொகு | — | ஏற்கனவே உள்ள உரை, நிரல் அல்லது தரவை மாற்றி அமைக்கும் செயல். |
| Embeddings | உட்பொதிவுகள் | உள்ளடக்குகள் | 'உள்' (inner) + 'அடக்கம்' (containment). சொற்கள் அல்லது தரவுகளை AI மாதிரி புரிந்துகொள்ளும் வகையில் எண்களாக (Vectors) மாற்றியமைக்கும் முறை. |
| Emergence | தோன்றுமியல்பு | — | சிறிய கூறுகளின் சேர்க்கையால், அவை தனித்தனியாக கொண்டிராத புதிய பண்புகள் தற்செயலாக வெளிப்படும் நிகழ்வு; Emergent Abilities-ன் அடிப்படைக் கருத்து. |
| Emergent Abilities | வெளிப்படும் திறன்கள் | தோன்றும் திறன்கள் | AI மாதிரியின் அளவு அதிகரிக்கும்போது, சிறிய மாதிரிகளில் இல்லாத புதிய திறன்கள் (உ-ம்: Instruction-following) தற்செயலாக வெளிப்படும் நிகழ்வு. |

| Emotion Detection | உணர்வுக் கண்டறிதல் | — | மனிதனின் உணர்வு நிலையை உரை, முகபாவம், ஒலியின் சுருதி அல்லது உடல் சைகைகள் வழியாகக் கண்டறியும் AI செயல்பாடு. |
| Emotional Prompting | உணர்வுத் தூண்டுதல் | உணர்வுநிலைக் கட்டளை | AI மாதிரியின் வெளியீட்டில் குறிப்பிட்ட உணர்வை எழுப்பும் விதத்தில் கட்டளை வடிவமைப்பு; AI-இன் உணர்வுத் தெரிவுத் (Affective Selection) திறனை மேம்படுத்த உதவுகிறது. |
| Encoder | குறியாக்கி | — | மனித உள்ளீட்டைக் கணினி புரிந்துகொள்ளும் உள்ளார்ந்த எண் தரவாக (Vector/Embedding) மாற்றும் பகுதி. |
| Environment Variable | சுற்றுப்புற மாறி | — | ஒரு மென்பொருள் அல்லது கணினி இயங்கும் சூழல் சார்ந்த அமைப்பு மதிப்புகளைச் சேமித்து வைக்கும் மாறும் தரவு. |
| Epoch | சுழற்சி | யுகம் | ஒரு AI மாதிரியை முழுப் பயிற்சித் தரவைப் பயன்படுத்தி ஒருமுறை பயிற்றுவித்தல்; பெரும்பாலான பயிற்சிகளில் பல சுழற்சிகள் தேவைப்படும். |
| Ethics in AI | செய்யறிவு நெறிமுறை | — | AI அமைப்புகளின் வடிவமைப்பு, பயன்பாடு மற்றும் தாக்கம் தொடர்பான நெறிமுறை, நேர்மை, பொறுப்புணர்வு மற்றும் சமூகச் சிக்கல்களை ஆராயும் துறை. |
| Evaluation | மதிப்பீடு | — | AI மாதிரியின் செயல்திறன், துல்லியம் மற்றும் பாதுகாப்பை அளவிடப் பயன்படுத்தப்படும் முறைகள் மற்றும் கருவிகள் (eval). |
| Explainability | விளக்கத்தகவு | — | AI மாதிரியின் முடிவுகளை மனிதர்கள் புரிந்துகொள்ளக்கூடிய அளவில் விளக்கும் பண்பு; Explainable AI-யின் அடிப்படைப் பண்பு. |
| Explainable AI (XAI) | விளக்கமளிக்கத்தக்க செய்யறிவு | — | AI மாதிரிகள் தங்கள் முடிவுகளை எவ்வாறு எடுத்தன என்பதை மனிதர்களுக்குப் புரியும் வகையில் விளக்கக்கூடிய திறன்; கருப்புப் பெட்டி (Black Box) பிரச்சினைக்கான தீர்வு. |
| F1 Score | F1 மதிப்பெண் | — | துல்லிய விகிதம் (Precision), மீட்டெடுப்பு விகிதத்தின் (Recall) சமநிலைச் சராசரி. |

| Fairness | நேர்மை| நீதிமை  | AI முடிவுகள் குறிப்பிட்ட குழுக்களுக்குச் சாதகமாகவோ பாதகமாகவோ இல்லாமல், பாரபட்சமின்றி நியாயமாக இருப்பதை உறுதிசெய்தல். |
| Feature Extraction | பண்பெடுப்பு | — | மூலத் தரவிலிருந்து பயனுள்ள பண்புகளை (Features) மட்டும் பிரித்தெடுக்கும் செயல்; இயந்திரக் கற்றலின் ஒரு முதன்மைப் படி. |
| Federated Learning | கூட்டமைப்புக் கற்றல் | ஒன்றியக் கற்றல் | தரவை மையத்திற்கு அனுப்பாமல், கருவிகளிலேயே பயிற்றுவித்துப் பயிற்சி முடிவுகளை மட்டும் ஒன்றிணைக்கும் பாதுகாப்பான கற்றல் முறை. |

| Ground Truth | அடிப்படை உண்மை | மெய்த்தரவு | மாதிரியின் கணிப்பை ஒப்பிட்டு மதிப்பிடப் பயன்படும் சரியான விடை/லேபிள். |
| Guardrails | பாதுகாப்பு வேலிகள் | நெறிமுறை வேலிகள் | AI மாதிரி தவறான, ஆபத்தான அல்லது ஆபாசமான பதில்களைத் தராமல் தடுக்க அதன் உள்ளீட்டிலும் வெளியீட்டிலும் வைக்கப்படும் கட்டுப்பாட்டு அடுக்குகள். |
| Hallucination | மதிமயக்கம் | பொய்யான உருவாக்கம் | 'மதி' (intellect) + 'மயக்கம்' (delusion). AI தவறான தகவலை உண்மையைப் போல நம்பிக்கையாக உருவாக்கும் நிலை. |
| Hallucination Mitigation | மதிமயக்கத் தடுப்பு | — | AI மாதிரிகள் தவறான தகவல்களை உண்மையைப் போலச் சொல்வதைத் தடுக்க அல்லது குறைக்கப் பயன்படுத்தப்படும் நுட்பங்கள் (உ-ம்: RAG). |
| Hallucination Rate | மதிமயக்க வீதம் | — | ஒரு AI மாதிரி கொடுக்கும் மொத்தப் பதில்களில் எத்தனை சதவீதம் மதிமயக்கப் பதில்கள் என அளவிடும் பிழை அளவீடு; benchmark மற்றும் evaluation-ல் முக்கிய அளவீடு. |
| Hyperparameter | மேலளபுரு | கட்டுப்பாட்டு அளபுரு | மாதிரி தானாகக் கற்றுக்கொள்ளாமல், பயிற்சிக்கு முன்பே வடிவமைப்பாளரால் முன்கூட்டியே அமைக்கப்படும் அளபுரு (உ-ம்: Learning Rate, Batch Size). |
| Image Generation | படவியற்றல் | பட உருவாக்கம் | உரைக் கட்டளைகள் அல்லது பிற உள்ளீடுகளின் அடிப்படையில் செய்யறிவைப் பயன்படுத்திப் புதிய படங்களை உருவாக்கும் செயல்முறை. |
| Inductive Reasoning | தொகுப்பு ஏரணம் | — | குறிப்பிட்ட பல அவதானிப்புகள் அல்லது உதாரணங்களை வைத்து, ஒரு பொதுவான விதியை அல்லது கணிப்பை உருவாக்கும் முறை (இயந்திரக் கற்றல் இதன் அடிப்படையில்தான் இயங்குகிறது). |
| Inference | முடிவுருவாக்கம் | அனுமானம் | AI மாதிரியைப் பயிற்றுவித்த பிறகு, அதைப் பயன்படுத்திப் புதிய உள்ளீட்டிற்குக் கணிப்பு அல்லது பதில் வழங்கும் செயல்முறை (பயிற்சிக்கு எதிர்மாறானது). |
| Inference Scaling | முடிவுருவாக்க நீட்சி | சோதனைநேர நீட்சி | inference-ன்போது (test-time) கூடுதல் கணிப்பு ஆதாரங்களைப் பயன்படுத்தி பதிலின் தரத்தை மேம்படுத்தும் முறை; o1, R1 போன்ற reasoning models-ன் அடிப்படை. |
| In-context Learning | சூழலுள் கற்றல் | — | எடுத்துக்காட்டுகளை prompt-லேயே கொடுத்து, நுண்திருத்தமின்றி மாதிரி கற்கும் முறை. |
| Instruction Tuning | கட்டளை நுண்திருத்தம் | — | பயனர் கட்டளைகளை AI மாதிரி துல்லியமாகப் பின்பற்ற உதவும் சிறப்பு நுண்திருத்தப் (Fine-tuning) பயிற்சி. |
| Internet of Things (IoT) | பொருள்களின் பிணையம் | — | இணையத்துடன் இணைக்கப்பட்ட அன்றாடப் பொருள்கள் (உணர்வேற்பிகள், கருவிகள்) ஒன்றோடொன்று தரவைப் பகிரும் வலையமைப்பு. |
| Interpretability | விளக்கத்திறன் | — | மாதிரி எப்படி முடிவெடுக்கிறது என்பதைப் புரிந்துகொள்ளும் அளவு; விளக்கமளிக்கத்தக்க செய்யறிவுடன் (Explainable AI) தொடர்புடையது. |
| Iterative Refinement | மீள்சீரமைப்பு | சீரமைப்புச் சுழற்சி | ஒரு விடையையோ வெளியீட்டையோ பல சுழற்சிகளாகத் திரும்பத் திரும்பச் செம்மைப்படுத்தி மேம்படுத்தும் முறை. |
| Jailbreak | விதிவிலக்கு ஊடுருவல் | பாதுகாப்பு மீறல் தூண்டல் | AI மாதிரியின் உள்ளமைக்கப்பட்ட பாதுகாப்புக் கட்டுப்பாடுகளையும் (Guardrails) அடிப்படை விதிகளையும் தந்திரோபாயமாக மீறச் செய்து, தடைசெய்யப்பட்ட பதில்களைப் பெறும் தாக்குதல் முறை. |
| K-skip-n-gram | க-தாவிய-எ-கிறுவம் | த-தாவிய-எ-கிறுவம் | உரைப்பகுப்பாய்வில் 'க' (K) எண்ணிக்கையிலான சொற்களைத் தாண்டி அமையும் 'எ' (N) அளவிலான சொற்றொடர் அமைப்பு. |
| Knowledge Base | அறிவுத்தளம் | — | ஒரு குறிப்பிட்ட துறை சார்ந்த தகவல்கள், தரவுகள் மற்றும் விதிகளைச் சேமித்து வைத்து விடையளிக்க உதவும் மையக் கட்டமைப்பு. |
| Knowledge Cutoff | அறிவு வரம்பு | — | AI மாதிரி பயிற்றுவிக்கப்பட்ட தரவின் கடைசித் தேதி; அதற்குப் பிறகான நிகழ்வுகள் மாதிரிக்குத் தெரியாது. |
| Knowledge Graph | அறிவு வரைபடம் | அறிவுத் தொடர்பமைப்பு | நிஜ உலகப் பொருள்கள், நிகழ்வுகள் அல்லது கருத்துகளுக்கு இடையிலான உறவுகளை வலைப்பின்னல் போன்று இணைத்துச் சேமிக்கும் கட்டமைப்பு. |
| KV Cache | விசை-மதிப்புத் தேக்ககம் | வி-ம தேக்ககம் | மாற்றுநர் (Transformer) மாதிரிகளில், முந்தைய சொல்துண்டுகளின் விசை (Key) மற்றும் மதிப்பு (Value) தரவுகளை நினைவகத்தில் சேமித்து வைத்து, உரை உருவாக்கத்தை வேகப்படுத்தும் நுட்பம். |
| Language Action Models (LAMs) | மொழிச் செயல் மாதிரி | — | மொழியைப் புரிந்துகொள்வது மட்டுமின்றி, மென்பொருள்களில் நேரடியாகச் செயல்களை (Actions) நிறைவேற்றும் திறன் கொண்ட AI மாதிரி. |
| Language Model (LM) | மொழி மாதிரி | மொழியொப்பாக்கம் | சொற்களின் தொடர்ச்சியைக் கணித்து, மனித மொழியைப் புரிந்துகொள்ளவும் உருவாக்கவும் வடிவமைக்கப்பட்ட AI கட்டமைப்பு. |
| Large Language Model (LLM) | பெருமொழி மாதிரி | மாமொழி மாதிரி | பில்லியன் கணக்கான அளபுருக்களையும் (Parameters) பரந்த தரவுகளையும் கொண்டு பயிற்றுவிக்கப்பட்ட மிகப்பெரிய மொழி மாதிரி. |
| Latency | செயல்தாமதம் | பின்னடைவு | பயனர் கோரிக்கைக்கும் AI மாதிரி அளிக்கும் பதிலுக்கும் இடையிலான நேர இடைவெளி; உண்மை நேர AI பயன்பாடுகளில் இது மிகக் குறைவாக இருக்க வேண்டும். |
| Latent Concept Models (LCMs) | உள்ளுறைக் கருத்துரு மாதிரி | — | தரவுகளில் வெளிப்படையாகத் தெரியாத, ஆனால் உள்ளீடுகளுக்குப் பின்னால் மறைந்திருக்கும் அடிப்படைக் கருத்துகளைக் (Latent concepts) கண்டறியும் மாதிரி. |
| Latent Space | உள்ளுறை வெளி | மறை வெளி | மாதிரி தரவின் அடிப்படைப் பண்புகளைச் சுருக்கிச் சேமிக்கும் எண் வெளி. |
| Layer | அடுக்கு | — | நரவலையின் ஒரு செயல்பாட்டு நிலை; உள்ளீட்டு அடுக்கு, மறை அடுக்குகள் மற்றும் வெளியீட்டு அடுக்கு எனப் பல நிலைகளைக் கொண்டது. |
| Leaderboard | முன்னிலைப் பட்டியல் | — | வெவ்வேறு AI மாதிரிகளின் செயல்திறன் அளவீடுகளை (Benchmarks) மதிப்பெண் அடிப்படையில் வரிசைப்படுத்திக் காட்டும் தரவரிசைப் பட்டியல். |
| Learning Objective | கற்றல் நோக்கம் | — | இயந்திரக் கற்றலின் போது ஒரு மாதிரி அடைய வேண்டிய இலக்கு அல்லது குறைக்க வேண்டிய பிழை அளவு. |
| Learning Rate | கற்றல் வீதம் | — | எடைகள் எவ்வளவு வேகமாகப் புதுப்பிக்கப்படுகின்றன என்பதைக் கட்டுப்படுத்தும் மேலளபுரு (Hyperparameter). |
| Logical Reasoning | ஏரணப் பகுத்தறிதல் | — | தரவுகளின் அடிப்படையில் காரண காரியங்களை ஆராய்ந்து ஏரணப்பூர்வமாக (Logically) முடிவெடுக்கும் திறன். |
| Logical Schema | ஏரண வரைவு | ஏரண மாதிரி | தரவுகள் மற்றும் விதிகளுக்கு இடையே உள்ள தொடர்புகளை முறையான ஏரண அமைப்பாக வடிவமைக்கும் வரைபடம். |
| Long Context | நீண்ட சூழல் | நீண்ட உள்ளீட்டு வரம்பு | மிக நீளமான உள்ளீட்டை (லட்சக்கணக்கான சொல்துண்டுகள்) ஒரே நேரத்தில் கையாளும் மாதிரித் திறன். |
| Low-Rank Adaptation (LoRA) | குறைவரிசைத் தழுவல் | குறை-சரிசெய்தல் சேர்க்கை | முழு மாதிரியையும் மாற்றாமல், குறைந்த அளவிலான கூடுதல் எடைகளை (Low-Rank Matrices) மட்டும் இணைத்துப் பயிற்றுவிக்கும் எடை-சிக்கன நுண்திருத்த (PEFT) முறை. |
| Loss Function | இழப்புச் சார்பு | பிழை அளவீடு | AI மாதிரியின் கணிப்புகளுக்கும் உண்மை மதிப்புகளுக்கும் இடையே உள்ள வேறுபாட்டை அளவிடும் கணிதச் சார்பு; பயிற்சியின்போது இதைக் குறைப்பதே முக்கிய நோக்கமாகும். |
| Machine Learning (ML) | இயந்திரக் கற்றல் | — | வெளிப்படையான நிரலாக்கம் இல்லாமல், தரவிலிருந்து தானாகவே கற்று வடிவங்களைக் கண்டறிந்து கணிப்புகளை வழங்கும் கணினியியல் துறை. |
| Machine Translation | இயந்திர மொழிபெயர்ப்பு | — | ஒரு மொழியிலிருந்து மற்றொரு மொழிக்குக் கணினி அல்லது AI மூலம் நேரடியாக மொழிபெயர்க்கும் நுட்பம். |
| Masked Language Models (MLMs) | திரைமூடிய மொழி மாதிரி | முகமூடிய மொழி மாதிரி | வாக்கியத்தில் மறைக்கப்பட்ட சொற்களைச் சூழலிலிருந்து கணிக்கப் பயிற்றுவிக்கப்படும் மாதிரி (BERT). |
| MCP (Model Context Protocol) | மாதிரிச் சூழல் நெறிமுறை | மாதிரிப் பின்புல நெறிமுறை | AI மாதிரிகள் வெளிப்புறக் கருவிகள்/தரவுத்தளங்களுடன் பாதுகாப்பாகத் தொடர்புகொள்ளும் தரப்படுத்தப்பட்ட நெறிமுறை. |
| Memory (AI context) | நினைவகம் | உரையாடல் நினைவகம் | AI உரையாடல் வரலாறு அல்லது நீண்டகாலத் தகவலைச் சேமித்துப் பயன்படுத்தும் திறன். |
| Meta Prompt | முதன்மைக் கட்டளை | — | பயனர் பேசத் தொடங்கும் முன்பே, AI எவ்வாறு நடந்து கொள்ள வேண்டும் என்று அதன் ஆளுமையை (Persona) மற்றும் கட்டுப்பாடுகளை வரையறுக்கும் பின்னணி வழிகாட்டுதல். |
| Metadata | மேந்தரவு | தரவுப்பின்னணி | தரவைப் பற்றிய தரவு; ஒரு கோப்பு அல்லது தகவலின் உருவாக்கம், அளவு, வகை போன்ற அடிப்படை விவரங்களைச் சுருக்கமாகக் குறிப்பது. |
| Mixture of Depths (MoD) | ஆழக் கலவை | — | Mixture of Experts (MoE)-க்கு இணையான நுட்பம்; ஒவ்வொரு tokens-க்கும் எவ்வளவு கணக்கீட்டு ஆழம் (compute depth) தேவை என்பதைத் தீர்மானித்து வளங்களை மிச்சப்படுத்தும் கட்டமைப்பு. |
| Mixture of Experts (MoE) Models | வல்லுநர் கலவை மாதிரி | வல்லுநர் கலவை | பல சிறப்புச் சிறிய நரவலைகளைக் (Experts) கொண்ட மாதிரி; ஒவ்வொரு உள்ளீட்டுக்கும் பொருத்தமான சில நரவலைகள் மட்டுமே செயல்படும். |
| Model Compression | மாதிரிச் சுருக்கம் | — | மாதிரியைச் சிறியதாகவும் வேகமாகவும் மாற்றுவதற்கான நுட்பங்கள் (உ-ம்: Quantization, Pruning). |
| Model Weights | மாதிரி எடைகள் | அளபுரு எடைகள் | ஒரு AI மாதிரி பயிற்சியின் போது தரவுகளிலிருந்து தானாகவே கற்றுக்கொள்ளும் எண்ணியல் மதிப்புகள். |
| MoE Routing | வல்லுநர் வழிப்படுத்தல் | — | Mixture of Experts (MoE) மாதிரியில், ஒவ்வொரு உள்ளீட்டுக்கும் (token) எந்த வல்லுநர் (expert) நரவலை செயல்பட வேண்டும் என்பதைத் தீர்மானிக்கும் வழிமுறை. |
| Multi-Agent System | பல்செயற்பாட்டாலி அமைப்பு | — | பல செயற்பாட்டாலிகள் இணைந்து ஒரு சிக்கலான இலக்கை அடையும் கட்டமைப்பு. |
| Multi-Head Attention | பன்தலைக் கவனம் | — | ஒரே உள்ளீட்டைப் பல கவனத் தலைகள் இணையாக ஆராய்ந்து பொருள் பிடிக்கும் Transformer நுட்பம். |
| Multimodal | பன்முக மாதிரி | — | உரை, படம், ஒலி, காணொளி போன்ற பல வகை உள்ளீடுகளைக் கையாளும் திறன் கொண்ட AI மாதிரி. |
| N-gram | எ-கிறுவம் | — | உரைப்பகுப்பாய்வில் 'எ' (N) எண்ணிக்கையிலான தொடர்ச்சியான உறுப்புகளின் (எழுத்துகள் அல்லது சொற்கள்) அமைப்பு. |
| N-gram Language Modelling | எ-கிறுவ மொழியொப்பாக்கம் | எ-கிறுவ மொழி மாதிரி | முந்தைய (N-1) சொற்களைப் பயன்படுத்தி அடுத்த சொல்லைக் கணிக்கும் ஒரு பாரம்பரிய உரை மாதிரி நுட்பம். |
| Named Entity Recognition (NER) | பெயருரு அறிதல் | பெயர்ச்சொல் உணர்தல் | உரையில் உள்ள மக்கள், இடங்கள், நிறுவனங்கள் போன்ற குறிப்பிட்ட பெயர்களைத் தானாகவே அடையாளம் கண்டு வகைப்படுத்தும் முறை. |
| Natural Language Processing (NLP) | இயன்மொழியாள்கை | இயற்கை மொழிச் செயலாக்கம் | மனித மொழியைக் கணினிகள் புரிந்துகொள்ள, பகுப்பாய்வு செய்ய மற்றும் உருவாக்க உதவும் செய்யறிவுப் பிரிவு. |
| Neural Networks | நரவலை | நரம்பணு வலைப்பின்னல் | மனித மூளையின் கட்டமைப்பைப் பின்பற்றித் தரவுகளில் உள்ள சிக்கலான வடிவங்களைக் கற்றுக்கொள்ளும் கணினி அமைப்பு. |
| Neural Search | நரவலைத் தேடல் | பொருள்சார் தேடல் | பாரம்பரியத் தேடல் போலக் குறிப்பிட்ட வார்த்தைகளை மட்டும் தேடாமல், நரவலைகளைப் பயன்படுத்திப் பயனர் கேட்கும் கேள்வியின் ஆழமான பொருளைப் புரிந்துகொண்டு தேடும் நுட்பம். |
| Ngram Vocabulary | கிறுவடைவு | எ-கிறுவ அகராதி | பயிற்சித் தரவிலிருந்து சேகரிக்கப்பட்ட அனைத்து எ-கிறுவங்களின் (N-grams) முழுமையான பட்டியல் அல்லது அகராதி. |
| OCR (Optical Character Recognition) | ஒளியியல் எழுத்துணர்தல் | ஒளிவழி எழுத்துணர்தல் | அச்சிடப்பட்ட அல்லது கையால் எழுதப்பட்ட ஆவணங்களைப் படம்பிடித்து, அதிலுள்ள எழுத்துகளைக் கணினி திருத்தக்கூடிய உரையாக மாற்றும் நுட்பம். |
| On-device AI | கருவியகச் செய்யறிவு | சாதனவழிச் செய்யறிவு | இணையத் தொடர்பின்றி, கருவியின் (உ-ம்: திறன்பேசி) சொந்த வன்பொருளைப் பயன்படுத்தியே தரவுகளைச் செயலாக்கும் AI அமைப்பு. |
| Ontology | பொருள் உறவுமுறை அமைப்பு | — | நிஜ உலகக் கருத்துகள் மற்றும் பொருள்களுக்கு இடையே உள்ள உறவுகளைக் கணினி புரிந்துகொள்ளும் வகையில் வடிவமைக்கப்படும் முறையான வரைபடம். |
| Open Source AI | திறந்த மூலச் செய்யறிவு | — | மூலக் குறியீடும் எடைகளும் பொதுவில் கிடைக்கும் AI மாதிரி. |
| Open Weight | திறந்த எடை | — | மாதிரி எடைகள் வெளியிடப்பட்டு, மூலக் குறியீடு மூடிய நிலையில் உள்ள AI வெளியீடு. |
| Optimizer | உகப்பாக்கி | — | எடைகளைப் புதுப்பிக்கும் நெறிமுறை (Adam, SGD); Gradient Descent-ன் செயல்படுத்தல். |
| Overfitting | மிகைப்பொருத்தம் | — | மாதிரி தான் படித்த பயிற்சித் தரவை மட்டும் அப்படியே மனப்பாடம் செய்துவிட்டு, புதிய தரவுகளுக்குத் தவறான பதில்களைத் தரும் நிலை. |
| Overparameterization | அளபுரு மிகைப்பு | — | பயிற்சிக்குத் தேவையானதை விட மிக அதிக அளபுருக்களைக் (Parameters) கொண்ட நிலை; தற்கால ஆழ்திறன் கற்றலில் இது பொதுவானது. |
| Parameter | அளபுரு | எடை | மாதிரி கற்றுக்கொள்ளும் எண்ணியல் மதிப்பு (Weights). ஒரு பெருமொழி மாதிரியில் (LLM) பில்லியன் கணக்கான அளபுருக்கள் இருக்கலாம். |
| Parameter-Efficient Fine-Tuning (PEFT) | அளபுருச் சிக்கன நுண்திருத்தம் | எடை-சிக்கன நுண்திருத்தம் | முழு மாதிரியின் அளபுருக்களையும் மாற்றாமல், சிறிய எண்ணிக்கையிலான அளபுருக்களை மட்டும் சேர்த்து அல்லது மாற்றி நுண்திருத்தம் செய்யும் முறை. |
| Part-of-Speech (POS) Tagging | சொல்வகைக் குறியிடுதல் | இலக்கணக் குறியிடுதல் | ஒரு வாக்கியத்தில் உள்ள ஒவ்வொரு வார்த்தையும் பெயர்ச்சொல், வினைச்சொல் போன்ற எந்த இலக்கண வகையைச் சேர்ந்தது என்று அடையாளம் காணும் பணி. |
| Perplexity | குழப்ப அளவு | திகைப்பளவு | ஒரு மொழி மாதிரி புதிய உரையைக் கணிக்கும்போது எவ்வளவு குழம்புகிறது என்பதை அளவிடும் குறியீடு; அளவு குறைந்தால் மாதிரியின் துல்லியம் அதிகம். |
| Positional Encoding | நிலைக் குறியீடு | இடக் குறியாக்கம் | Transformer-ல் சொல்துண்டுகளின் வரிசை நிலையை எண்களாகச் சேர்க்கும் முறை. |
| Precision | துல்லிய விகிதம் | — | மாதிரி சரியாகக் கண்டறிந்தவற்றில் எத்தனை உண்மையில் சரியானவை என்பதைக் காட்டும் அளவீடு (Classification metric). |
| Pretraining | முன்பயிற்சி | — | ஒரு மாதிரியைக் குறிப்பிட்ட பணிக்கு நுண்திருத்தம் (Fine-tuning) செய்யும் முன், பெரிய பொதுத் தரவுகளில் அடிப்படை மொழியறிவைப் பயிற்றுவித்தல். |
| Probabilistic Reasoning | நிகழ்தகவு ஏரணம் | — | நிகழ்தகவு அடிப்படையில் முடிவெடுக்கும் தர்க்க முறை; திட்டவட்ட ஏரணத்திற்கு (Deterministic Reasoning) எதிர்மறை. |
| Programming Language | நிரலாக்க மொழி | கணினி மொழி | கணினிக்குக் கட்டளைகளை வழங்கப் பயன்படுத்தப்படும் முறையான மொழி. |
| Prompt | தூண்டுவினா | கட்டளை | AI-யிடம் வேலை வாங்க நாம் கொடுக்கும் உள்ளீடு அல்லது அறிவுறுத்தல். |
| Prompt Chaining | தூண்டல் சங்கிலி | கட்டளைச் சங்கிலி | ஒரு prompt-ன் வெளியீட்டை அடுத்த prompt-க்கு உள்ளீடாகத் தொடர்ந்து இணைத்து, சிக்கலான பல படிநிலைப் பணிகளை நிறைவேற்றும் முறை. |
| Prompt Engineering | தூண்டுவினாவியல் | கட்டளை வடிவமைப்பு | வினா' (question) + 'வியல்' (field of study). தூண்டுவினா நுட்பம். AI மாதிரியிடமிருந்து சிறந்த பதிலைப் பெறுவதற்காக உள்ளீட்டுக் கட்டளைகளைத் (Prompts) துல்லியமாக வடிவமைக்கும் முறை. |
| Prompt Injection | தூண்டுவினா ஊடுருவல் | கட்டளை ஊடுருவல் | AI-க்கு வழங்கப்படும் உள்ளீட்டில் தீங்கான கட்டளைகளைச் செருகி, அதன் அடிப்படை விதிகளை மீறச் செய்யும் தாக்குதல் முறை. |
| Pruning | வெட்டித்திருத்தம் | — | மாதிரிச் சுருக்க (Model Compression) நுட்பம்; தேவையற்ற அல்லது குறைந்த முக்கியத்துவம் கொண்ட எடைகளை (Weights) நீக்கி, மாதிரியின் அளவையும் கணக்கீட்டுச் சுமையையும் குறைக்கும் முறை. |
| Quantization | எண்ணளவாக்கம் | துல்லியச் சுருக்கம் | மாதிரியின் எடைகளை உயர் துல்லியத்திலிருந்து (32-bit) குறைந்த துல்லியத்திற்கு (8/4-bit) சுருக்கி, நினைவகமும் வேகமும் மேம்படுத்தும் நுட்பம். |
| Question Answering (QA) | வினா-விடை | — | கொடுக்கப்பட்ட சூழலிலிருந்து கேள்விக்கு விடை கண்டறியும் NLP பணி. |
| Reasoning Chain | ஏரணச் சங்கிலி | பகுத்தறிவுச் சங்கிலி | Chain of Thought (CoT)-க்கு மாற்றுச் சொல்; ஒரு முடிவை எட்டுவதற்காக AI மாதிரி பின்பற்றும் தர்க்கரீதியான படிநிலைகளின் தொடர். |
| Reasoning Model | ஏரண மாதிரி | பகுத்தறிவு மாதிரி | தகவல்களை வெறுமனே மனப்பாடம் செய்யாமல், காரண காரியங்களை ஆராய்ந்து தர்க்கரீதியாக முடிவெடுக்கும் திறன் கொண்ட AI மாதிரி. |
| Recall | மீட்டெடுப்பு விகிதம் | — | தரவில் உள்ள உண்மையானவற்றில் எத்தனை மாதிரியால் கண்டறியப்பட்டன என்பதைக் காட்டும் அளவீடு. |
| Recurrent Neural Networks (RNN) | பின்னூட்ட நரவலை | மீள்சுற்று நரவலை | முந்தைய வெளியீட்டைத் தற்போதைய உள்ளீட்டின் ஒரு பகுதியாகப் பயன்படுத்தித் தொடர்ச்சியான தரவுகளைக் (உ-ம்: மொழி, நேரம்) கையாளும் நரவலை. |
| Red Teaming | சிவப்பு அணி சோதனை | — | AI மாதிரியின் பாதுகாப்பு, பிழைகள் மற்றும் சாய்வுகளைக் கண்டறியத் திட்டமிட்ட தாக்குதல் அல்லது சவால் கேள்விகள் மூலம் சோதனை செய்யும் முறை. |
| Regularization | சீரமைப்பு | ஒழுங்குமுறைப்படுத்தல் | மிகைப்பொருத்தத்தைக் (Overfitting) குறைக்கப் பயிற்சியில் கட்டுப்பாடுகள் விதிக்கும் நுட்பங்கள் (Dropout, Weight Decay). |
| Reinforcement Learning (RL) | வலுவூட்டல் கற்றல் | — | ஒரு செயற்பாட்டாலி (Agent) சூழலோடு தொடர்புகொண்டு, செயல்களுக்கான வெகுமதிகள் அல்லது தண்டனைகள் மூலம் தாமாகவே கற்றுக் கொள்ளும் இயந்திரக் கற்றல் முறை. |
| Reinforcement Learning from Human Feedback (RLHF) | மனிதப் பின்னூட்ட வலுவூட்டல் கற்றல் | மனித வெகுமதி வலுவூட்டல் கற்றல் | மனித விருப்பங்களுக்கு ஏற்ப AI-இன் வெளியீடுகளைச் சீரமைக்கும் சிறப்புப் பயிற்சி முறை. |
| Relation Extraction | தொடர்பு பிரித்தெடுத்தல் | உறவு கண்டறிதல் | உரையில் கண்டறியப்பட்ட இரண்டு பொருள்களுக்கு அல்லது நபர்களுக்கு இடையே உள்ள உறவை (எ.கா: "மின்னஞ்சல்" என்பது "தொடர்பு சாதனம்") தானாகவே கண்டறிந்து வகைப்படுத்தும் முறை. |
| Responsible AI | பொறுப்பான செய்யறிவு | — | நேர்மை, வெளிப்படைத்தன்மை, பொறுப்புணர்வுடன் வடிவமைக்கப்படும் AI. |
| Retrieval-Augmented Generation (RAG) | மீட்டெடுப்பு-மேம்படுத்திய இயற்றல் | மீட்டெடுப்பு சார்ந்த உரை உருவாக்கம் | வெளிப்புறத் தரவுத்தளங்களிலிருந்து தகவல்களை மீட்டெடுத்துத் துல்லியமான பதிலை உருவாக்கும் கட்டமைப்பு. |
| Reward Model | வெகுமதி மாதிரி | பாராட்டு மாதிரி | AI தரும் பதில்களில் எது சிறந்தது என்று மனிதனைப் போலவே மதிப்பிட்டுப் புள்ளிகள் வழங்கும் துணைக் கணினி மாதிரி (RLHF-இல் பயன்படுகிறது). |
| RL from AI Feedback (RLAIF) | AI பின்னூட்ட வலுவூட்டல் கற்றல் | — | RLHF-ன் மாற்று முறை; மனிதர்களின் பின்னூட்டத்திற்குப் பதிலாக மற்றொரு AI மாதிரியின் கருத்துக்களைப் பயன்படுத்தி வலுவூட்டல் கற்றலை மேற்கொள்ளும் முறை (Anthropic Constitutional AI-ல் பயன்படுகிறது). |
| Robustness | வலுவுறுதி | உறுதித்தன்மை | எதிர்பாராத உள்ளீடுகள், இரைச்சல், அல்லது தாக்குதல்கள் (Adversarial Attacks) ஏற்படும்போதும் AI மாதிரி நிலையாக, துல்லியமாகச் செயல்படும் திறன். |
| Sampling Strategy | மாதிரி எடுத்தல் உத்தி | சொல் தேர்வு முறை | AI மாதிரி அடுத்த சொல்லைத் தேர்ந்தெடுக்கும்போது பயன்படுத்தும் தர்க்கரீதியான வழிமுறை (உ-ம்: Top-K, Top-P, Temperature). |
| Scalar | தன்மதிப்பு | ஒற்றை மதிப்பு | ஒரே ஒரு எண்ணைக் கொண்ட மதிப்பு; Vector (திசையன்), Tensor (பன்மதிப்புக் கணம்) ஆகியவற்றுக்கு எதிர்மறை. |
| Segment Anything Models (SAMs) | கூறு ஏதேனும் மாதிரி | ஏதும்கூறு மாதிரி | படத்திலுள்ள எந்தவொரு பொருளையும் முன்கூட்டியே அறியாமலேயே துல்லியமாகப் பிரித்து (Segment) அடையாளம் காணும் கணினியியல் பார்வை மாதிரி. |
| Self-Attention | தன்கவனம் | தன்கவனிப்பு | உள்ளீட்டின் ஒவ்வொரு பகுதியும், அதே உள்ளீட்டின் மற்ற பகுதிகளுடன் எவ்வாறு தொடர்புபடுகிறது என்பதைக் கணக்கிடும் வழிமுறை; மாற்றுநரின் (Transformer) அடிப்படை. |
| Self-Consistency | தன்முறை ஒருமை | — | Chain of Thought (CoT)-ல் ஒரே கேள்விக்குப் பல சிந்தனைப் பாதைகளை உருவாக்கி, அதிகம் ஒருமித்த விடையை இறுதி முடிவாகத் தேர்ந்தெடுக்கும் நுட்பம். |
| Self-supervised Learning | தன்மேற்பார்வைக் கற்றல் | — | லேபிளிடாத தரவிலிருந்து தானே மேற்பார்வைச் சமிக்ஞைகளை உருவாக்கிக் கற்கும் முறை (BERT, GPT). |
| Semantic Kernel | பொருள்சார் அகடு | கருத்தியல் கருவம் | பாரம்பரிய நிரலாக்க மொழிகளுடன் (C#, Python) பெருமொழி மாதிரிகளை (LLMs) எளிதாக இணைக்க மைக்ரோசாப்ட் (Microsoft) உருவாக்கிய திறந்த மூலக் கட்டமைப்பு. |
| Semantic Textual Similarity | பொருள்சார் உரை ஒப்புமை | — | இரண்டு வெவ்வேறு வாக்கியங்கள் ஒரே வார்த்தைகளைக் கொண்டிருக்காவிட்டாலும், அவற்றின் ஒட்டுமொத்தப் பொருள் எவ்வளவு ஒத்துப் போகிறது என்பதை எண்களால் அளவிடுதல். |
| Semi-supervised Learning | அரைமேற்பார்வைக் கற்றல் | — | சிறிது லேபிளிட்ட தரவும் பெரும்பான்மை லேபிளிடாத தரவும் கலந்த கற்றல் முறை. |
| Sentiment Analysis | உணர்வுப் பகுப்பாய்வு | — | ஒரு உரையின் மொத்த உணர்வுச் சார்பை (நேர்மறை, எதிர்மறை, நடுநிலை) அளவிடும் இயன்மொழியாள்கை (NLP) நுட்பம். |
| Sentiment Detection | சொற்சுவையறிதல் | உணர்வுக் கண்டறிதல் | வார்த்தைகளில் பொதிந்துள்ள உள்நோக்கத்தையோ சுவையையோ துல்லியமாகக் கண்டறியும் செயல்முறை. |
| Sequence-to-Sequence (Seq2Seq) | தொடர்-முதல்-தொடர் | — | ஒரு வரிசையை (உ-ம்: வாக்கியம்) மற்றொரு வரிசையாக மாற்றும் மாதிரி; இயந்திர மொழிபெயர்ப்பு மற்றும் உரைச் சுருக்கத்திற்குப் பயன்படுகிறது. |
| Server | வழங்கி | சேவையகம் | தரவுகளைச் சேமித்து வைத்து, வலையமைப்பில் உள்ள பிற கணினிகளுக்கு (Clients) சேவைகளை அல்லது தகவல்களை வழங்கும் மையக் கணினி. |
| Skipgram | தாவிய-கிறுவம் | — | உரைப்பகுப்பாய்வில் ஒரு குறிப்பிட்ட மையச் சொல்லை வைத்து, அதைச் சுற்றியுள்ள (முன் மற்றும் பின்) சொற்களைக் கணிக்கும் மாதிரி. |
| Small Language Models (SLMs) | சிறுமொழி மாதிரி | குறுமொழி மாதிரி | பெருமொழி மாதிரிகளைப் (LLMs) போலன்றி, குறைவான அளபுருக்களைக் (Parameters) கொண்டு ஒரு குறிப்பிட்ட பணிக்காகச் சிறப்பாகச் செயல்பட வடிவமைக்கப்பட்ட மாதிரி. |
| Social Media | சமூக ஊடகம் | — | இணையத்தின் வழியே மக்கள் தகவல்களையும் கருத்துகளையும் பகிர்ந்துகொள்ளவும் தொடர்புகொள்ளவும் உதவும் தளங்கள். |
| Softmax | மென்மை-அதிகபடி சார்பு | — | நரவலையின் வெளியீட்டு மதிப்புகளை நிகழ்தகவு விநியோகமாக (Probability Distribution) மாற்றும் கணிதச் செயல்பாடு; வகைப்பாட்டில் (Classification) பயன்படுகிறது. |
| Sparse Model | அரிது மாதிரி | சிதறல் மாதிரி | பல எடைகள் (Weights) பூஜ்யத்திற்கு அருகில் இருக்கும் மாதிரி; இதனால் குறைந்த கணக்கீட்டுத் திறனிலேயே செயல்பட முடிகிறது. |
| Speculative Decoding | ஊகக் குறிநீக்கம் | முன்மதிப்பீட்டு விடையாக்கம் | சிறிய மாதிரி ஊகிக்க, பெரிய மாதிரி சரிபார்க்க — இரட்டை மாதிரி வேகமூட்டும் நுட்பம். |
| Speech Recognition | பேச்சுணர்தல் | குரலறிதல் | மனிதப் பேச்சைக் கணினி அல்லது மென்பொருள் உணர்ந்து புரிந்துகொள்ளும் தொழில்நுட்பம். |
| Speech-to-Text (STT) | பேச்சு-முதல்-உரை | ஒலி-உரை மாற்றம் | மனிதப் பேச்சை அல்லது ஒலியைப் புரிந்துகொண்டு அதை எழுத்துப்பூர்வமான உரையாக மாற்றும் நுட்பம். |

| Structured Output | கட்டமைக்கப்பட்ட வெளியீடு | — | LLM வெளியீட்டை JSON போன்ற நிலையான கட்டமைப்பில் தரும் திறன். |
| Supervised Learning | மேற்பார்வையிட்ட கற்றல் | — | லேபிளிடப்பட்ட (உள்ளீடு-வெளியீடு ஜோடி) தரவுகளைப் பயன்படுத்தி AI மாதிரியைப் பயிற்றுவிக்கும் முறை (உ-ம்: வகைப்பாடு). |
| Summarization | சுருக்கமிடுதல் | உரைச் சுருக்கம் | நீண்ட உரையின் முக்கிய கருத்துகளைச் சிறிய வடிவில் தரும் NLP பணி. |
| Symbolism | குறியியக்கியம் | — | விதிகளையும் தர்க்கங்களையும் (Logic and Rules) பயன்படுத்தித் தரவுகளைக் குறியீடுகள் மூலம் மனித அறிவாகக் கணினிக்குப் புகட்டும் முற்காலச் செய்யறிவு அணுகுமுறை. |
| Synchronous | ஒன்னேர் | ஒத்திசைந்த | செயல்பாடுகள் ஒரே நேரத்தில் அல்லது ஒரு குறிப்பிட்ட வரிசையில் ஒன்றன்பின் ஒன்றாகத் தடங்கலின்றிச் செயல்படும் முறை. |
| Synthetic Data | செயற்கைத் தரவு | புனைவுத் தரவு | கணினி அல்லது AI மூலம் செயற்கையாக உருவாக்கப்படும் பயிற்சித் தரவு. |
| System Prompt | அமைப்புத் தூண்டல் | அமைப்பு வழிகாட்டுதல் | AI-க்கு அதன் பாத்திரம், நடத்தை, கட்டுப்பாடுகளை வரையறுக்கும் ஆரம்ப அறிவுறுத்தல். |
| Temperature | பல்வகைமை அளவு | சீரின்மை அளவு / கற்பனை அளவு | AI வெளியீட்டின் கற்பனைத் தன்மை மற்றும் சீரின்மையைக் கட்டுப்படுத்தும் அளவீடு. குறைந்த அளவு (0–0.3) துல்லியமான பதிலையும், அதிக அளவு (0.7–1.0+) புதுமையான பதிலையும் தரும். |
| Tensor | பன்மதிப்புக் கணம் | — | பல பரிமாணங்களைக் கொண்ட எண்களின் அமைப்பு (Multi-dimensional Array); Scalar (ஒற்றை), Vector (ஒரு பரிமாண), Matrix (இரு பரிமாண) ஆகியவற்றின் பொதுவான வடிவம். ஆழ்திறன் கற்றலின் அடிப்படைத் தரவு வடிவம். |
| Test-Time Compute | சோதனைநேரக் கணிப்பு | — | AI மாதிரி பயிற்சி முடிந்து inference நிலையில் (test-time) ஒவ்வொரு பதிலுக்கும் பயன்படுத்தப்படும் கணக்கீட்டு ஆதாரங்கள்; reasoning models-ல் இதை அதிகரிப்பதால் பதிலின் தரம் மேம்படுகிறது. |
| Testing | சோதனை | சரிபார்ப்பு | ஒரு மாதிரி அல்லது மென்பொருள் எதிர்பார்த்தபடி செயல்படுகிறதா, பிழைகள் ஏதும் உள்ளதா என்பதை உறுதிசெய்யும் செயல்முறை. |
| Text-to-Speech (TTS) | உரை-முதல்-பேச்சு | உரை-பேச்சு மாற்றம் | எழுதப்பட்ட உரையைக் கணினி மூலம் ஒலியாக (பேச்சாக) மாற்றிக் கேட்கச் செய்யும் அமைப்பு. |
| Token | சொல்துண்டு | சொல் அலகு | AI மாதிரி வாசிக்கும் அல்லது உருவாக்கும் மொழியின் மிகச்சிறிய அலகு (ஒரு சொல் அல்லது சொல்லின் பகுதி). |
| Token Limit | சொல்துண்டு வரம்பு | உள்ளீட்டு வரம்பு | ஒரு மொழி மாதிரி ஒரே நேரத்தில் வாசிக்கக்கூடிய அல்லது உருவாக்கக்கூடிய அதிகபட்சச் சொல்துண்டுகளின் (Tokens) எண்ணிக்கை. |
| Tokenizer | சொல்துண்டாக்கி | — | உரையைச் சொல்துண்டுகளாகப் (Tokens) பிரிக்கும் கருவி (BPE, SentencePiece). |
| Toolformer | கருவியமைப்பி | கருவி-மாற்றுநர் | கால்குலேட்டர்கள், தேடுபொறிகள் போன்ற வெளிப்புறக் கருவிகளை எப்பொழுது, எப்படிப் பயன்படுத்த வேண்டும் என்று தானாகவே கற்றுக்கொள்ளும் மொழி மாதிரி. |
| Top-K Sampling | உயர்-K மாதிரி எடுத்தல் | — | அடுத்த சொல்லைத் தேர்ந்தெடுக்கும்போது அதிக நிகழ்தகவு (Probability) கொண்ட முதல் 'K' எண்ணிக்கையிலான சொற்களை மட்டும் கட்டுப்படுத்தும் முறை. |
| Top-P (Nucleus Sampling) | அணுகுத் தொகுதி மாதிரி எடுத்தல் | தொகுப்பு வரம்பு | அடுத்த சொல்லைத் தேர்ந்தெடுக்கும்போது குறிப்பிட்ட சதவீத ஒட்டுமொத்த நிகழ்தகவு (Cumulative Probability) கொண்ட சொற்களை மட்டும் கணக்கில் கொள்ளும் முறை. |
| Transfer Learning | இடமாற்றக் கற்றல் | பரவல் கற்றல் | ஒரு பணிக்காகப் பயிற்றுவிக்கப்பட்ட மாதிரியின் அறிவை, மற்றொரு தொடர்புடைய பணிக்குப் பயன்படுத்தும் முறை; அடிப்படை மாதிரிகளின் (Foundation Models) அடித்தளம். |
| Transformer | மாற்றுநர் | மாற்றி | தன்கவன (Self-Attention) வழிமுறையைப் பயன்படுத்தித் தொடர்ச்சியான தரவுகளை (குறிப்பாக மொழியை) இணையாகச் செயலாக்கும் ஆழ்திறன் நரவலைக் கட்டமைப்பு (உ-ம்: GPT, BERT). |
| Tree of Thoughts (ToT) | சிந்தனை மரம் | — | Chain of Thought (CoT)-ன் விரிவாக்கம்; ஒரு சிக்கலைத் தீர்க்க பல சிந்தனைப் பாதைகளை மரக் கட்டமைப்பில் ஒருங்கே ஆராய்ந்து, சிறந்ததைத் தேர்ந்தெடுக்கும் முறை. |
| Unsupervised Learning | மேற்பார்வையற்ற கற்றல் | — | லேபிளிடப்படாத தரவுகளிலிருந்தே வடிவங்கள், கொத்துகள் மற்றும் அமைப்புகளைத் தானாகவே கண்டறியும் இயந்திரக் கற்றல் முறை. |
| User Prompt | பயனர் தூண்டல் | பயனர் கட்டளை | பயனர் AI-க்கு வழங்கும் கேள்வி அல்லது கட்டளை (அமைப்புத் தூண்டலுடன் இணைந்து செயல்படுகிறது). |
| Validation Set | சரிபார்ப்புத் தொகுதி | — | பயிற்சியின் போது மாதிரியின் செயல்திறனை மதிப்பிடப் பயன்படுத்தப்படும் தனிப்பட்ட தரவு (பயிற்சி, சரிபார்ப்பு, சோதனை என தரவு மூன்றாகப் பிரிக்கப்படும்). |
| Vector Database | திசையன் தரவுத்தளம் | திசையன் தரவு மையம் | பொதிவுகளை (Embeddings) சேமித்து ஒப்புமைத் தேடல் செய்யும் தரவுத்தளம்; RAG-ன் அடிப்படை. |
