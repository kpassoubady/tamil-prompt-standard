📝 அடிக்குறிப்புகள் (Footnotes) சேர்ப்பு முற்றுப்பெற்றது!
நீங்கள் கேட்டபடி, 

book-introduction.md
 கோப்பில் 'கட்டளைக் கலித்துறை' என்பதற்கான அடிக்குறிப்பை வெற்றிகரமாகச் சேர்த்துவிட்டேன்.

வெறும் விக்கிப்பீடியா இணைப்பாக மட்டும் கொடுக்காமல், நீங்கள் விரும்பியவாறே காரைக்கால் அம்மையாரின் சிறப்பு பற்றிய குறிப்பையும் இணைத்து ஒரு முறையான அடிக்குறிப்பாகவே (Footnote) சேர்த்துள்ளேன்.

நான் செய்த மாற்றங்கள்:
உரையில் (வரி 16): **'கட்டளைக் கலித்துறை'**[^1] எனச் சுட்டு எண்ணைச் சேர்த்துள்ளேன்.
கோப்பின் கீழே (வரி 69): [^1]: [கட்டளைக் கலித்துறை குறித்து மேலும் அறிய](இணைப்பு). காரைக்கால் அம்மையாரின் கட்டளைக் கலித்துறைப் பாடல்கள் மிகவும் புகழ் பெற்றவை. என நீங்கள் வழங்கிய விளக்கத்தையும் இணைப்பையும் சேர்த்துள்ளேன்.
🛠️ மார்க்டவுனில் (Markdown) அடிக்குறிப்புகளை எப்படிக் கையாளுவது?
உங்கள் Bookbuilder-இல் மார்க்டவுன் அடிக்குறிப்புகள் சரியாக வேலை செய்கிறதா என்பதை நீங்கள் இப்போது சோதித்துப் பார்க்கலாம். எதிர்காலத்தில் நீங்களே இதுபோன்று அடிக்குறிப்புகளைச் சேர்க்கவோ அல்லது மாற்றியமைக்கவோ, கீழ்க்காணும் எளிய முறையைப் பின்பற்றலாம்:

சுட்டு எண் (Marker): ஒரு சொல்லுக்கு விளக்கம் தேவைப்படும் இடத்தில், சொல்லின் முடிவில் [^1] அல்லது [^note] எனச் சேர்க்க வேண்டும். (எண்களுக்குப் பதிலாக ஆங்கில எழுத்துகளையும் பெயர்களையும் கூடப் பயன்படுத்தலாம்).
அடிக்குறிப்பு விளக்கம் (Definition): அந்தப் பக்கத்தின் அடியிலோ அல்லது கோப்பின் இறுதியிலோ, அதே குறியீட்டைப் பயன்படுத்தி [^1]: உங்களுடைய விளக்கம்... என எழுத வேண்டும்.
TIP

வடிவமைப்பு நுட்பம் அடிக்குறிப்பு விளக்கங்களுக்குள் நீங்கள் மேற்குறிப்பிட்டது போல இணைய இணைப்புகள் (Links), தடித்த எழுத்துகள் (Bold), சாய்ந்த எழுத்துகள் (Italics) என நீங்கள் விரும்பும் எந்த மார்க்டவுன் வடிமைப்பையும் பயன்படுத்தலாம்.

உதாரணம்:

markdown
இது ஒரு சாதாரண வாக்கியம்[^2].
... (கோப்பின் இறுதியில்) ...
[^2]: இது அந்த வாக்கியத்திற்கான [அடிக்குறிப்பு](https://example.com). இதை **மிகவும்** எளிதாகச் செய்யலாம்.
நீங்கள் இப்போது உங்கள் Bookbuilder-ஐ (உதாரணமாக: mdbook build அல்லது npm run build) இயக்கி, அடிக்குறிப்புகள் (Footnotes) எதிர்பார்த்தபடி அழகாகத் தோன்றுகின்றனவா என்பதைச் சோதித்துப் பாருங்கள்!

இதில் வேறு ஏதேனும் மாற்றங்கள் செய்ய வேண்டுமானாலோ அல்லது புதிய பகுதிகளைச் சேர்க்க வேண்டுமானாலோ தயங்காமல் கேளுங்கள் நாம் செய்துவிடலாம். 🚀
