# கலைச்சொல் அட்டவணை

இந்த நூலின் பல்வேறு கட்டளைகளில் பயன்படுத்தப்பட்ட ஆங்கில தொழில்நுட்ப சொற்களுக்கான தமிழ் விளக்கங்கள் — துறை வாரியாக தொகுக்கப்பட்டவை.

---

## செய்யறிவு & கட்டளை நுட்பம்

| ஆங்கிலம் | தமிழ் | விளக்கம் |
|---------|-------|---------|
| Artificial Intelligence (AI) | செய்யறிவு | மனித அறிவை போன்று செயல்படும் இயந்திர அறிவியல் |
| Generative AI | ஈனும் செய்யறிவு | உரை, படம், ஒலி ஆகியவற்றை உருவாக்கும் AI |
| Large Language Model (LLM) | பெரு மொழி-மாதிரி | மொழியை புரிந்து உருவாக்கும் பெரிய AI மாதிரி |
| Prompt | தூண்டுவினா / கட்டளை | AI-க்கு கொடுக்கும் உள்ளீட்டு வினா அல்லது அறிவுறுத்தல் |
| Prompt Engineering | தூண்டுவினா நுட்பம் | சிறந்த AI பதில் பெற கட்டளைகளை வடிவமைக்கும் திறன் |
| Token | சொல்துண்டு | AI மாதிரி மொழியை பகுக்கும் சிறு அலகு |
| Hallucination | மதி மயக்கம் | AI தவறான தகவலை உண்மை என்று கூறும் நிலை |
| Algorithm | நெறிமுறை | ஒரு பணியை படிப்படியாக செய்வதற்கான வழிமுறை |
| Software | மென்பொருள் | கணினி இயக்கத்திற்கான நிரல்கள் |

## சுகாதாரம்

| ஆங்கிலம் | தமிழ் | விளக்கம் |
|---------|-------|---------|
| SOAP | அகநிலை, புறநிலை, மதிப்பீடு, திட்டம் | மருத்துவ குறிப்பு வடிவம்: Subjective, Objective, Assessment, Plan |
| EMR (Electronic Medical Records) | இலத்திரனியல் மருத்துவ பதிவுகள் | டிஜிட்டல் நோயாளி தகவல் அமைப்பு |
| ICD | நோய் வகைப்படுத்தல் குறியீடு | உலக சுகாதார அமைப்பின் நோய் குறியீட்டு முறை |
| BP (Blood Pressure) | இரத்த அழுத்தம் | தமனிகளில் இரத்தம் செல்லும் அழுத்தம் |
| AYUSH | ஆயுர்வேதம், யோகா, யுனானி, சித்தா, ஓமியோபதி | இந்திய பாரம்பரிய மருத்துவ முறைகளின் தொகுப்பு |
| WHO | உலக சுகாதார அமைப்பு | World Health Organization — சுகாதார தரநிலைகளை நிர்ணயிக்கும் ஐ.நா. அமைப்பு |

## தொழில்நுட்பம்

| ஆங்கிலம் | தமிழ் | விளக்கம் |
|---------|-------|---------|
| API (Application Programming Interface) | பயன்பாட்டு நிரலிடை | இரு மென்பொருள்களுக்கிடையே தொடர்பு கொள்ள வழிதரும் இடைமுகம் |
| RESTful API | நிலை பரிமாற்ற கட்டமைப்பு | Representational State Transfer — வலை சேவை வடிவமைப்பு முறை |
| HTTP Method | தகவல் பரிமாற்ற நெறிமுறை | GET, POST, PUT, DELETE — வலை கோரிக்கை வகைகள் |
| JSON (JavaScript Object Notation) | கட்டமைப்பு தரவு வடிவம் | தரவு பரிமாற்றத்திற்கான எளிய உரை வடிவம் |
| JWT (JSON Web Token) | வலை அடையாள சான்று | பயனர் அங்கீகாரத்திற்கான குறியாக்கப்பட்ட சான்று |
| OAuth | திறந்த அங்கீகார நெறிமுறை | மூன்றாம் தரப்பு உள்நுழைவு அனுமதி முறை |
| SOLID | ஒற்றைப்பொறுப்பு கொள்கைகள் | தரமான நிரல் வடிவமைப்பிற்கான 5 அடிப்படை கொள்கைகள் |
| OpenAPI (Swagger) | திறந்த API ஆவண தரநிலை | API-ஐ விவரிக்கும் தரப்படுத்தப்பட்ட ஆவண வடிவம் |
| docstring | ஆவண வரி | செயல்பாட்டின் நோக்கத்தை விளக்கும் குறியீட்டு உரை |
| Internet | இணையம் | உலகளாவிய கணினி வலையமைப்பு |
| Search Engine | தேடல் பொறி | Google, Bing போன்ற உரை-தேடும் கருவி |

## வேலைவாய்ப்பு

| ஆங்கிலம் | தமிழ் | விளக்கம் |
|---------|-------|---------|
| ATS (Applicant Tracking System) | விண்ணப்பதாரர் கண்காணிப்பு முறை | ரெசுமேக்களை தானாகத் தரவரிசைப்படுத்தும் மென்பொருள் |
| STAR Method | சூழல்-பணி-நடவடிக்கை-விளைவு முறை | Situation, Task, Action, Result — நேர்காணல் பதில் வடிவம் |
| GPA (Grade Point Average) | தர புள்ளி சராசரி | கல்வி செயல்திறனை அளவிடும் எண் மதிப்பு |
| HR (Human Resources) | மனித வளங்கள் | நிறுவனத்தில் பணியாளர் மேலாண்மை துறை |
| Resume | வாழ்க்கை விவரக் குறிப்பு | கல்வி, அனுபவம் கொண்ட தொழில்முறை ஆவணம் |
| Fresher | புதிய பட்டதாரி | வேலை அனுபவம் இல்லாத புதிய வேலைவாய்ப்பாளர் |

## சமூக ஊடகம்

| ஆங்கிலம் | தமிழ் | விளக்கம் |

| SEO (Search Engine Optimization) | தேடுபொறி மேம்பாடு | வலைத்தளம் / வீடியோ தேடல் முடிவுகளில் தோன்ற உதவும் நுட்பம் |

| CTA (Call To Action) | செயல் அழைப்பு | பார்வையாளரை ஒரு குறிப்பிட்ட செயல் செய்ய தூண்டும் வரி |
