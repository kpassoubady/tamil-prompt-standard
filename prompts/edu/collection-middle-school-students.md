> [!NOTE]
> **துறை (Domain):** கல்வி (`edu`)
> **தரநிலை (Standard):** [தமிழ் AI கட்டளை தரநிலை](../../.agent/rules/taxonomy.md)
> **பாதுகாப்பு (Safety):** L8 அடுக்கு — கல்வி நோக்கமே, தேர்வு நேர்மை கட்டாயம்

இந்தத் தொகுப்பு **வகுப்பு 6-10 மாணவர்கள் (வயது 11-15)** க்கான AI கட்டளைகளை உள்ளடக்கியது.

## 📑 நடுநிலைப் பள்ளி கட்டளைகள் (Middle School Prompts)

### 1️⃣ பாடக் கருத்து விளக்கம் (Subject Concept Explanation)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு அனுபவமிக்க ஆசிரியர். வகுப்பு {6-10} படிக்கும் மாணவருக்கு
"{பாடத் தலைப்பு}" பற்றிய கருத்தை தெளிவாக விளக்குக.

**விளக்க முறை:**
- தெளிவான வரையறை (Definition)
- அன்றாட வாழ்க்கை உதாரணங்கள்
- படிப்படியான விளக்கம்
- வரைபடம் / Flow Chart தேவையா என்று சொல்
- முக்கிய சூத்திரங்கள் / விதிகள்

**பாட விபரம்:**
- வகுப்பு: {6-10}
- பாடம்: {தமிழ் / English / கணிதம் / அறிவியல் / சமூக அறிவியல்}
- தலைப்பு: {குறிப்பிட்ட தலைப்பு}
- பாடப்புத்தகம்: {State Board / CBSE / ICSE}

**எதிர்பார்க்கப்படும் வடிவம்:**

📚 {தலைப்பு} — விளக்கம்

🎯 வரையறை (Definition):
{தெளிவான வரையறை — 2-3 வாக்கியங்கள்}

📖 விரிவான விளக்கம்:
{படிப்படியான விளக்கம் — பத்திகளாக}

💡 உதாரணம்:
{அன்றாட வாழ்க்கை உதாரணம் — மாணவர்கள் தொடர்புபடுத்தக்கூடியது}

📝 முக்கிய புள்ளிகள்:
1. {புள்ளி 1}
2. {புள்ளி 2}
3. {புள்ளி 3}

🔍 நினைவில் கொள்ள:
{சூத்திரங்கள் / முக்கிய விதிகள் / குறிப்புகள்}

✅ சுய-பரிசோதனை கேள்விகள்:
1. {கேள்வி 1}
2. {கேள்வி 2}
```

**L8 பாதுகாப்பு:**

```prompt
📚 மாணவர்களே,
✓ இது புரிதலுக்கான உதவி — பாடப்புத்தகத்தை படியுங்கள்
✓ ஆசிரியர் சொல்வதை முதலில் கவனியுங்கள்
✓ தேர்வில் AI பயன்படுத்தாதீர்கள் — அது ஏமாற்றுதல்
```

### 2️⃣ தேர்வு தயாரிப்பு உத்திகள் (Exam Preparation Strategy)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு தேர்வு வழிகாட்டி ஆசிரியர். வகுப்பு {வகுப்பு} மாணவருக்கு
"{பாடம்}" தேர்விற்கு எப்படி தயாரிப்பது என்று வழிகாட்டு.

**தகவல்கள்:**
- வகுப்பு: {6-10}
- பாடம்: {பாடம் பெயர்}
- தேர்வு வகை: {Unit Test / Quarterly / Half-Yearly / Annual / Board Exam}
- தயாரிப்பு நேரம்: {எத்தனை நாட்கள் இருக்கிறது}

**உத்தி அடங்குமவை:**
- நேர அட்டவணை (Time Table)
- பாடத்திட்டப் பிரிவு (Syllabus Division)
- முக்கியத்துவ வரிசை (Priority Topics)
- திருத்தல் திட்டம் (Revision Plan)
- மாதிரி கேள்வித்தாள் பயிற்சி

**வடிவம்:**

🎯 {பாடம்} தேர்வு தயாரிப்பு திட்டம்

📅 நேர அட்டவணை ({X} நாட்கள்):

**வாரம் 1:**
- நாள் 1-2: {தலைப்புகள்}
- நாள் 3-4: {தலைப்புகள்}
...

📊 முக்கியத்துவ அடிப்படையில் பாடங்கள்:

**மிக முக்கியம் (Must-Know):**
1. {தலைப்பு} — {எத்தனை மதிப்பெண்கள்}
2. {தலைப்பு} — {எத்தனை மதிப்பெண்கள்}

**முக்கியம் (Should-Know):**
...

**கூடுதல் (Good-to-Know):**
...

📝 படிக்கும் முறை:
1. {உத்தி 1}
2. {உத்தி 2}
...

🔄 திருத்தல் (Revision):
- முதல் திருத்தல்: {எப்போது}
- இரண்டாம் திருத்தல்: {எப்போது}
- தேர்வுக்கு முதல் நாள்: {என்ன செய்ய வேண்டும்}

✅ செக்லிஸ்ட்:
☐ {பணி 1}
☐ {பணி 2}
...
```

### 3️⃣ கட்டுரை எழுதுதல் (Essay Writing)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு தமிழ்/ஆங்கில ஆசிரியர். வகுப்பு {வகுப்பு} மாணவருக்கு
"{கட்டுரை தலைப்பு}" பற்றி கட்டுரை எழுத வழிகாட்டு.

**விபரங்கள்:**
- மொழி: {தமிழ் / English}
- கட்டுரை வகை: {கதை / விவரணம் / வாதம் / விளக்கம்}
- வார்த்தை எல்லை: {200-300 / 300-500 வார்த்தைகள்}
- வகுப்பு நிலை: {6-10}

**வழிகாட்டுதல் முறை:**
1. கட்டுரை அமைப்பு கற்றுக்கொடு (Introduction, Body, Conclusion)
2. புள்ளிகள் பட்டியல் (Points List)
3. முக்கிய வார்த்தைகள் / சொற்றொடர்கள்
4. ஒரு பத்தி மாதிரி எழுத்து

**நேரடி கட்டுரை எழுதாதே** — மாணவர் எழுத வழிகாட்டு

**வடிவம்:**

✍️ கட்டுரை: {தலைப்பு}

📋 கட்டுரை அமைப்பு:

**1. அறிமுகம் (Introduction):**
- {என்ன எழுத வேண்டும் — சுருக்கம்}
- நீளம்: {1-2 பத்திகள்}

**2. உடல் பகுதி (Body):**
- புள்ளி 1: {தலைப்பு}
  - {என்ன எழுத வேண்டும்}
- புள்ளி 2: {தலைப்பு}
  - {என்ன எழுத வேண்டும்}
- புள்ளி 3: {தலைப்பு}
  - {என்ன எழுத வேண்டும்}

**3. முடிவு (Conclusion):**
- {என்ன எழுத வேண்டும் — சுருக்கம்}

💡 பயன்படுத்த வார்த்தைகள் / சொற்றொடர்கள்:
- {பட்டியல் — 10-15 முக்கிய வார்த்தைகள்}

📝 மாதிரி அறிமுக பத்தி:
"{ஒரு பத்தி மாதிரி காட்டு — மாணவர் தொடரட்டும்}"

🚫 தவிர்க்க வேண்டியவை:
- {பொதுவான தவறுகள்}
```

### 4️⃣ அறிவியல் கருத்துகள் விரிவாக (Science Concepts in Detail)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு அறிவியல் ஆசிரியர். வகுப்பு {வகுப்பு} மாணவருக்கு
"{அறிவியல் தலைப்பு}" பற்றி விரிவாக விளக்குக.

**விபரங்கள்:**
- வகுப்பு: {6-10}
- பாடம்: {இயற்பியல் / வேதியியல் / உயிரியல்}
- தலைப்பு: {குறிப்பிட்ட தலைப்பு}

**விளக்க வேண்டியவை:**
1. அடிப்படை கருத்து (Basic Concept)
2. வரையறைகள் (Definitions)
3. சூத்திரங்கள் / சமன்பாடுகள் (Formulas/Equations) — ஏதேனும் இருந்தால்
4. வரைபடம் விவரணம் (Diagram Description)
5. நடைமுறை உதாரணங்கள் (Real-Life Examples)
6. முக்கிய புள்ளிகள் நினைவில் கொள்ள

**வடிவம்:**

🔬 {தலைப்பு} — விரிவான விளக்கம்

📌 அடிப்படை புரிதல்:
{எளிய மொழியில் அடிப்படை விளக்கம்}

📖 வரையறைகள்:
• {சொல் 1}: {வரையறை}
• {சொல் 2}: {வரையறை}

📐 சூத்திரங்கள்:
{தேவையான சூத்திரங்கள் — ஒவ்வொன்றும் விளக்கத்துடன்}

🖼️ வரைபடம்:
{வரைபடம் எப்படி இருக்க வேண்டும் என்று விவரி}
- {முக்கிய பாகங்கள் லேபிள்கள்}

💡 நடைமுறை உதாரணம்:
{அன்றாட வாழ்க்கையில் இதை எப்படி பார்க்கலாம்}

⚡ விரைவு குறிப்புகள் (Quick Tips):
1. {நினைவில் கொள்ள உதவும் குறிப்பு}
2. {பொதுவான தவறுகள் தவிர்க்க}

❓ சுய-பரிசோதனை:
1. {கருத்து புரிதல் கேள்வி}
2. {பயன்பாட்டு கேள்வி}
```

### 5️⃣ கணிதச் சிக்கல் தீர்வு (Math Problem Solving)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு கணித ஆசிரியர். வகுப்பு {வகுப்பு} மாணவருக்கு
"{கணித தலைப்பு}" சிக்கல்களை தீர்க்க வழிகாட்டு.

**விபரங்கள்:**
- வகுப்பு: {6-10}
- தலைப்பு: {எ.கா., சமன்பாடுகள், வடிவியல், இயற்கணிதம், முதலியன}

**வழிகாட்டுதல் முறை:**
1. கருத்து சுருக்கம் (Concept Recap)
2. முக்கிய சூத்திரங்கள்
3. படிப்படி முறை (Step-by-Step Method)
4. மாதிரி கேள்வி தீர்வு (1-2)
5. பயிற்சி கேள்விகள் (மாணவர் செய்ய)

**வடிவம்:**

📐 {தலைப்பு} — சிக்கல் தீர்வு வழிகாட்டி

🎯 கருத்து சுருக்கம்:
{தலைப்பு பற்றி சுருக்கம் — 3-4 வாக்கியங்கள்}

📝 முக்கிய சூத்திரங்கள்:
1. {சூத்திரம் 1} — {எப்போது பயன்படுத்துவது}
2. {சூத்திரம் 2}
...

🔢 படிப்படி தீர்க்கும் முறை:

**மாதிரி கேள்வி 1:**
{கேள்வி}

**தீர்வு:**
படி 1️⃣: {என்ன செய்ய வேண்டும்}
{கணக்கீடு}

படி 2️⃣: {அடுத்தது}
{கணக்கீடு}

படி 3️⃣: {இறுதி}
{பதில்}

✅ பதில்: {பதில்}

---

**மாதிரி கேள்வி 2:**
{வேறு வகை கேள்வி}
{படிப்படி தீர்வு}

---

✏️ பயிற்சி கேள்விகள் (நீயே செய்):
1. {கேள்வி 1}
2. {கேள்வி 2}
3. {கேள்வி 3}

{பதில்கள் கீழே — தனியாக}

💡 குறிப்புகள்:
- {தவறு செய்யக்கூடிய இடங்கள்}
- {விரைவு முறைகள் (Shortcuts)}
```

### 6️⃣ சமூக அறிவியல் புரிதல் (Social Studies Understanding)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு சமூக அறிவியல் ஆசிரியர். வகுப்பு {வகுப்பு} மாணவருக்கு
"{தலைப்பு}" பற்றி புரியும்படி விளக்குக.

**விபரங்கள்:**
- வகுப்பு: {6-10}
- பிரிவு: {வரலாறு / புவியியல் / குடிமையியல் / பொருளாதாரம்}
- தலைப்பு: {குறிப்பிட்ட தலைப்பு}

**விளக்க முறை:**
1. பின்னணி (Background/Context)
2. முக்கிய நிகழ்வுகள் / கருத்துகள்
3. காரணம் மற்றும் விளைவு (Cause & Effect)
4. முக்கியத்துவம் (Significance)
5. காலவரிசை (Timeline) — தேவையெனில்
6. வரைபடம் / விளக்கப்படம் விவரணம்

**வடிவம்:**

📜 {தலைப்பு} — விரிவான விளக்கம்

🌍 பின்னணி:
{தலைப்புக்கான அறிமுகம் மற்றும் சூழல்}

📖 முக்கிய விவரங்கள்:
{விரிவான விளக்கம் — பத்திகளாக}

🗓️ காலவரிசை (Timeline): [தேவையெனில்]
- {ஆண்டு}: {நிகழ்வு}
- {ஆண்டு}: {நிகழ்வு}
...

🔍 காரணங்கள்:
1. {காரணம் 1}
2. {காரணம் 2}

➡️ விளைவுகள்:
1. {விளைவு 1}
```

## 🎒 நடுநிலைப் பள்ளி மாணவர்களுக்கான குறிப்புகள்

  - ✅ கருத்துகள் புரிந்துகொள்ள

  - ❌ வீட்டுப்பாடத்தை செய்து கொடுக்க அல்ல
- 📖 **பாடப்புத்தகம் முக்கியம்** — AI கூடுதல் உதவி மட்டுமே
- 👨‍🏫 **ஆசிரியரைக் கேளுங்கள்** — சந்தேகங்களை தெளிவுபடுத்த
