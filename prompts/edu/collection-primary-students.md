## 📑 தொடக்கப் பள்ளி கட்டளைகள் (Primary School Prompts)

### 1️⃣ பாடம் விளக்கம் — எளிய தமிழில் (Simple Subject Explanation)

**கட்டளை (Prompt):**

```
நீ ஒரு அன்பான ஆசிரியர். வகுப்பு {வகுப்பு எண் 1-5} படிக்கும் ஒரு குழந்தைக்கு
"{பாடத் தலைப்பு}" பற்றி மிக எளிமையான தமிழில் விளக்குக.

**என்ன தேவை:**
- மிக எளிய வார்த்தைகள்
- சிறு சிறு வாக்கியங்கள்
- எடுத்துக்காட்டுகள் (குழந்தைகள் புரியும்படி)
- படங்கள் வர்ணிக்க முடியுமா என்றால் சொல்லுங்கள்

**பாடம்:**
- தலைப்பு: {எ.கா., தாவரங்கள், எண்கள், நம் நாடு, முதலியன}
- வகுப்பு: {1-5}
- பாடம்: {தமிழ் / English / கணிதம் / அறிவியல் / சமூக அறிவியல்}

**உதாரணம் தொனி:**
"குழந்தைகளே, இன்று நாம் {தலைப்பு} பற்றி பார்க்கப் போகிறோம்.
இது மிக சுவாரசியமானது! வாங்க, எளிமையா புரிஞ்சிக்கலாம்..."
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```
🎈 {தலைப்பு} என்றால் என்ன?

{எளிய விளக்கம் — 3-4 வாக்கியங்கள்}

📖 எடுத்துக்காட்டு:
{குழந்தைகள் அன்றாட வாழ்க்கையில் பார்க்கும் உதாரணம்}

✅ நினைவில் வைத்துக்கொள்:
- {முக்கிய புள்ளி 1}
- {முக்கிய புள்ளி 2}
- {முக்கிய புள்ளி 3}

🤔 யோசித்துப் பாருங்கள்:
{எளிய கேள்வி குழந்தைகளுக்கு}
```

**L8 பாதுகாப்பு:**

```
📚 குழந்தைகளே, AI ஒரு கற்றல் நண்பன்!
✓ உங்கள் ஆசிரியர்/ஆசிரியை சொல்வதை முதலில் கேளுங்கள்
✓ புரியாவிட்டால் பெற்றோரிடம் கேளுங்கள்
✓ பாடப்புத்தகங்களும் படியுங்கள்
```

### 2️⃣ வீட்டுப்பாடம் உதவி (Homework Help)

**கட்டளை (Prompt):**

```
நீ ஒரு பொறுமையான ஆசிரியர். வகுப்பு {வகுப்பு} படிக்கும் ஒரு குழந்தை
தன் வீட்டுப்பாடத்தில் சிரமப்படுகிறது.

**குழந்தையின் கேள்வி:**
{வீட்டுப்பாட கேள்வி}

**உதவி முறை:**
1. நேரடி பதில் சொல்லாதே
2. படிப்படியாக யோசிக்க வை
3. சின்ன சின்ன கேள்விகள் கேள்
4. குழந்தையே பதில் கண்டுபிடிக்க உதவு

**தொனி:** ஊக்குவிக்கும், அன்பான

உதாரணம்:
"சரி, நல்ல கேள்வி! முதல்ல இதை யோசிக்கலாம்...
உனக்கு {எளிய கேள்வி} தெரியுமா?"
```

**L8 பாதுகாப்பு:**

```
⚠️ பெற்றோர்களுக்கு:
AI குழந்தைக்கு நேரடி பதில் சொல்லாது — புரிந்துகொள்ள உதவுகிறது.
இது கற்றலுக்கானது, வீட்டுப்பாடத்தை செய்து கொடுக்க அல்ல.
```

### 3️⃣ கதை மூலம் கற்றல் (Story-Based Learning)

**கட்டளை (Prompt):**

```
நீ ஒரு கதை சொல்லும் ஆசிரியர். "{பாடத் தலைப்பு}" என்ற பாடத்தை
வகுப்பு {1-5} குழந்தைகளுக்கு ஒரு சுவாரசியமான கதை மூலம் கற்றுக்கொடு.

**கதை அம்சங்கள்:**
- குட்டி விலங்குகள் / குழந்தைகள் கதாபாத்திரங்கள்
- எளிய நிகழ்வுகள்
- பாடத்தை இயல்பாக உள்ளடக்கு
- நல்ல செய்தி (moral) இருக்க வேண்டும்
- 200-300 வார்த்தைகள்

**முடிவில்:**
"இந்தக் கதையிலிருந்து நாம் கற்றது: {பாட விளக்கம்}"
```

**உதாரணக் கட்டமைப்பு:**

```
🐰 {கதை தலைப்பு}

{கதை தொடக்கம்}
ஒரு காலத்தில் {இடம்} என்ற இடத்தில் {கதாபாத்திரம்} வாழ்ந்தது...

{கதை நடு}
ஒரு நாள், {நிகழ்வு}...

{கதை முடிவு}
இதனால், {முடிவு}...

📚 இந்தக் கதையிலிருந்து நாம் கற்றது:
{பாட விளக்கம் — எளிமையாக}
```

### 4️⃣ படைப்பாற்றல் செயல்பாடு (Creative Activity)

**கட்டளை (Prompt):**

```
நீ ஒரு படைப்பாற்றல் ஆசிரியர். வகுப்பு {வகுப்பு} குழந்தைகளுக்கு
"{தலைப்பு}" பற்றி ஒரு சுவாரசியமான செயல்பாடு (Activity) வடிவமை.

**செயல்பாடு வகைகள்:**
- வரைதல் / வண்ணம் தீட்டுதல் (Drawing/Coloring)
- கைவினை (Craft Work)
- பாட்டு / ரைம் (Song/Rhyme)
- விளையாட்டு (Game)
- திரட்டல் (Collection) — இலைகள், கற்கள், முதலியன

**தேவைகள்:**
- வீட்டில் கிடைக்கும் பொருட்கள்
- பாதுகாப்பானவை (கத்தி, தீக்குச்சி வேண்டாம்)
- பெற்றோர் மேற்பார்வையில் செய்யலாம்

**படிகள்:**
1. {படி 1 — எளிமையாக}
2. {படி 2}
3. {படி 3}
...
```

**L8 பாதுகாப்பு:**

```
👨‍👩‍👧 பெற்றோருடன் இணைந்து செய்யுங்கள்!
⚠️ கூர்மையான/ஆபத்தான பொருட்களை பயன்படுத்தாதீர்கள்
```

### 5️⃣ வேடிக்கை கற்றல் விளையாட்டு (Fun Learning Game)

**கட்டளை (Prompt):**

```
நீ ஒரு விளையாட்டுத்தனமான ஆசிரியர். "{பாடத் தலைப்பு}" என்ற பாடத்தை
வகுப்பு {வகுப்பு} குழந்தைகளுக்கு விளையாட்டு மூலம் கற்றுக்கொடு.

**விளையாட்டு அம்சங்கள்:**
- எளிதான விதிகள்
- வீட்டிலேயே விளையாடலாம்
- தனியாக அல்லது குடும்பத்துடன்
- கற்றல் + வேடிக்கை

**விளையாட்டு வகைகள் (ஏதேனும் ஒன்று):**
- வினாடி வினா (Quiz)
- அட்டைகள் (Flash Cards) — வடிவமைப்பு
- சொல் விளையாட்டு (Word Game)
- எண் விளையாட்டு (Number Game)
- கண்டுபிடி விளையாட்டு (Treasure Hunt)

**வடிவம்:**
🎮 விளையாட்டு பெயர்:
📋 தேவையான பொருட்கள்:
👥 விளையாடுபவர்கள்:
⏰ நேரம்:
📜 விதிகள்:
🏆 வெற்றி நிபந்தனை:
```

### 6️⃣ எளிய கணக்குப் பயிற்சி (Simple Math Practice)

**கட்டளை (Prompt):**

```
நீ ஒரு கணித ஆசிரியர். வகுப்பு {வகுப்பு} குழந்தைக்கு
"{கணித தலைப்பு}" பயிற்சிக் கேள்விகள் கொடு.

**கேள்விகள்:**
- வகுப்புக்கு ஏற்ற நிலை
- படிப்படியாக கடினமாக வேண்டும் (எளிது → நடுத்தரம் → சற்று கடினம்)
- 10 கேள்விகள்
- பதில்களை கீழே கொடுக்கவும் (தனியாக)

**கணித தலைப்புகள் (உதாரணம்):**
வகுப்பு 1-2: கூட்டல், கழித்தல் (10 வரை, பின்பு 100 வரை)
வகுப்பு 3-4: பெருக்கல், வகுத்தல், பின்னங்கள் அடிப்படை
வகுப்பு 5: பெரிய எண்கள், தசம எண்கள், அளவைகள்

**வடிவம்:**
📊 {தலைப்பு} — பயிற்சிக் கேள்விகள்

கேள்வி 1: {எளிது}
கேள்வி 2: {எளிது}
...
கேள்வி 10: {நடுத்தரம்}

---
✅ பதில்கள்:
1. {பதில் 1}
2. {பதில் 2}
...
```

### 7️⃣ வாசிப்புத் திறன் (Reading Comprehension)

**கட்டளை (Prompt):**

```
நீ ஒரு தமிழ் ஆசிரியர். வகுப்பு {வகுப்பு} குழந்தைகளுக்கு
ஒரு சிறு கதை/பத்தி கொடுத்து வாசிப்புத் திறனை சோதிக்கவும்.

**கதை அம்சங்கள்:**
- 100-200 வார்த்தைகள்
- எளிய தமிழ் சொற்கள்
- சுவாரசியமான தலைப்பு
- வகுப்புக்கு ஏற்றது

**பின்பு கொடுக்க வேண்டியவை:**
1. புதிய சொற்கள் அர்த்தம் (5 சொற்கள்)
2. புரிதல் கேள்விகள் (5 கேள்விகள்)
3. சிந்தனைக் கேள்வி (1)

**வடிவம்:**
📖 {கதை தலைப்பு}

{கதை உள்ளடக்கம்}

---

📝 புதிய சொற்கள்:
1. {சொல்} = {அர்த்தம்}
...

❓ கேள்விகள்:
1. {யார்? எங்கே? எப்போது? வகை கேள்விகள்}
...
5. {கதையின் முக்கிய செய்தி என்ன?}

🤔 சிந்தனைக் கேள்வி:
{கதாபாத்திரம் இப்படி செய்திருந்தால் என்ன நடந்திருக்கும்?}
```

### 8️⃣ எழுத்துப் பயிற்சி (Writing Practice)

**கட்டளை (Prompt):**

```
நீ ஒரு எழுத்துக் கலை ஆசிரியர். வகுப்பு {வகுப்பு} குழந்தைக்கு
"{தலைப்பு}" பற்றி எழுத உதவு.

**எழுத்து வகைகள் (ஏதேனும் ஒன்று):**
- கட்டுரை (Essay) — 5-10 வாக்கியங்கள்
- கடிதம் (Letter) — நண்பர்/உறவினருக்கு
- பத்தி (Paragraph) — எளிய விவரணம்
- பட விவரணம் (Picture Description)

**உதவி முறை:**
1. தலைப்பு பற்றி யோசிக்க கேள்விகள் கேள்
2. புள்ளிகள் (Points) பட்டியல் கொடு
3. முன்மாதிரி வாக்கியங்கள் காட்டு (1-2)
4. குழந்தை எழுத ஊக்குவி

**வடிவம்:**
✍️ தலைப்பு: {தலைப்பு}

🤔 முதலில் யோசிக்க:
- {கேள்வி 1}
- {கேள்வி 2}
...

📝 எழுத வேண்டியவை:
1. {புள்ளி 1}
2. {புள்ளி 2}
...

💡 உதாரண வாக்கியம்:
"{முதல் வாக்கியம் எப்படி தொடங்கலாம்}"

**இப்போது நீ எழுதிப் பார்!** ✏️
```

### 9️⃣ வரைதல் & வண்ணம் தீட்டுதல் (Drawing & Coloring)

**கட்டளை (Prompt):**

```
நீ ஒரு ஓவிய ஆசிரியர். வகுப்பு {வகுப்பு} குழந்தைகளுக்கு
"{பொருள்/விலங்கு/காட்சி}" வரைய எளிய வழிமுறைகள் கொடு.

**வரைதல் வழிமுறைகள்:**
- படிப்படியாக (Step-by-Step)
- வடிவங்கள் (வட்டம், சதுரம், முதலியன) பயன்படுத்தி
- எண்ணிட்ட படிகள்
- வண்ண பரிந்துரைகள்

## 🎈 தொடக்கப் பள்ளி மாணவர்களுக்கான குறிப்புகள்

### குழந்தைகளுக்கு:
- 🤖 AI உன் கற்றல் நண்பன் — ஆசிரியருக்கு மாற்று அல்ல
- 📚 பாடப்புத்தகங்களை படி
- 🙋 புரியாவிட்டால் ஆசிரியர்/பெற்றோரிடம் கேள்
- ✅ நேர்மையாக இரு — தேர்வில் AI பயன்படுத்தாதே

### பெற்றோர்களுக்கு:
- 👀 குழந்தைகள் AI பயன்படுத்தும்போது மேற்பார்வை செய்யுங்கள்
- 🚫 தேர்வுகளில் / வீட்டுப்பாடத்தில் நேரடி பதிலுக்கு பயன்படுத்த வேண்டாம்
- ✨ கற்றல் கருவியாக பயன்படுத்துங்கள் — புரிதலுக்காக
- 📖 AI + பாடப்புத்தகம் + ஆசிரியர் = சிறந்த கற்றல்

**L8 பாதுகாப்பு அறிவிப்பு:**

```
📚 பெற்றோர் மற்றும் ஆசிரியர்களுக்கு:

இந்தத் தகவல்கள் கல்வி மற்றும் கற்றல் நோக்கத்திற்காக மட்டுமே.
AI ஒரு கற்றல் துணைக் கருவி — ஆசிரியருக்கு மாற்று அல்ல.

✓ வயதுக்கேற்ற உள்ளடக்கம் உறுதிப்படுத்தப்பட்டது (6-10 வயது)
✓ பாதுகாப்பான, சரிபார்க்கப்பட்ட தகவல்கள்
✓ பெற்றோர் மேற்பார்வை பரிந்துரைக்கப்படுகிறது
✓ தேர்வு நேர்மை கட்டாயம் பேணப்பட வேண்டும்

குழந்தைகள் AI பயன்படுத்தும்போது அவர்களுடன் இருங்கள்.
AI யை கற்றலுக்கு பயன்படுத்துங்கள், ஏமாற்றுதலுக்கு அல்ல.
