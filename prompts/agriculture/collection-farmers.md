## 📑 விவசாய கட்டளைகள் (Farming Prompts)

### 1️⃣ பயிர் பரிந்துரை (Crop Recommendation)

**கட்டளை (Prompt):**

```
நீ ஒரு அனுபவமிக்க வேளாண்மை நிபுணர். என் நிலத்திற்கு என்ன பயிர் சாகுபடி செய்யலாம் என்று பரிந்துரை செய்.

**என் நிலம் பற்றிய தகவல்கள்:**
- மாவட்டம்: {உங்கள் மாவட்டம்}
- கிராமம்: {கிராமம் பெயர்}
- நில அளவு: {ஏக்கர் / ஹெக்டேர்}
- மண் வகை: {சிவப்பு மண் / கருப்பு மண் / களிமண் / மணல் கலந்த மண்}
- நீர் வசதி: {கால்வாய் / கிணறு / போர்வெல் / மழை நீர் மட்டும்}
- பருவம்: {குறுவை / சம்பா / தாளடி / நான்காவது பருவம்}
- முந்தைய பயிர்: {என்ன பயிர் செய்தேன்}

**எதிர்பார்க்கும் தகவல்கள்:**
- ஏற்ற பயிர் பரிந்துரை (2-3 வகைகள்)
- ஏன் இந்த பயிர்? (காரணங்கள்)
- மகசூல் எவ்வளவு எதிர்பார்க்கலாம்?
- செலவு எவ்வளவு ஆகும்?
- சந்தை தேவை எப்படி இருக்கிறது?
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```

📊 உங்கள் நிலம் பகுப்பாய்வு:
- மண்: {வகை}
- நீர்: {வசதி}
- அளவு: {ஏக்கர்}

### 2️⃣ இயற்கை விவசாயம் (Organic Farming)

**கட்டளை (Prompt):**

```
நீ ஒரு இயற்கை விவசாய நிபுணர். எனக்கு "{பயிர் பெயர்}" பயிருக்கு
இயற்கை விவசாய முறையை விரிவாக விளக்குக.

**பயிர் விவரம்:**
- பயிர்: {நெல் / தக்காளி / வாழை / கரும்பு / முதலியன}
- நில அளவு: {ஏக்கர்}
- தற்போது பயன்படுத்தும் முறை: {ரசாயன உரம் / கலவை / இயற்கை}

**விளக்க வேண்டியவை:**
1. இயற்கை விதை தயாரிப்பு / நேர்த்தி
2. மண் ஆரோக்கியம் மேம்படுத்துதல்
3. இயற்கை உரங்கள் (எப்படி தயாரிப்பது)
4. இயற்கை பூச்சிக்கொல்லிகள்
5. நீர் நிர்வாகம்
6. களை மேலாண்மை
7. மகசூல் மற்றும் தரம்

**எளிய தமிழில், படிப்படியாக விளக்கவும்.**
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```
🌿 {பயிர்} — இயற்கை விவசாய முறை

📖 இயற்கை விவசாயம் என்றால் என்ன?

இயற்கை விவசாயம் என்பது ரசாயன உரங்கள், பூச்சிக்கொல்லிகள் இல்லாமல்,
இயற்கை முறைகளை மட்டும் பயன்படுத்தி சாகுபடி செய்வது.

**நன்மைகள்:**
- மண் வளம் மேம்படும்
- ஆரோக்கியமான உணவு
- செலவு குறைவு (நீண்ட கால)
- சுற்றுச்சூழல் பாதுகாப்பு
- நல்ல விலை (Organic சான்றிதழ் பெற்றால்)

---

🌱 படிப்படி இயற்கை விவசாய முறை:

**படி 1: விதை தயாரிப்பு & நேர்த்தி**

**விதை தேர்வு:**
- நல்ல தரமான, நாட்டு ரக விதைகளை தேர்ந்தெடுக்கவும்
- {பயிர் க்கு ஏற்ற ரகம்: {ரக பெயர்கள்}}

**இயற்கை விதை நேர்த்தி:**
```
தேவையான பொருட்கள்:
- பசு மூத்திரம்: 1 லிட்டர்
- மஞ்சள் தூள்: 50 கிராம்
- சுண்ணாம்பு: சிறிது

முறை:
1. பசு மூத்திரத்துடன் மஞ்சள் தூள் கலக்கவும்
2. விதைகளை இந்த கலவையில் 6-8 மணி நேரம் ஊற வைக்கவும்
3. நிழலில் உலர்த்தவும்
4. சுண்ணாம்பு தூவி விதைக்கவும்
```

---

**படி 2: மண் ஆரோக்கியம் மேம்படுத்துதல்**

**பஞ்சகவ்யா தயாரிப்பு:** (மிக முக்கியம்!)

```
தேவையான பொருட்கள்:
- பசு சாணம்: 5 கிலோ
- பசு மூத்திரம்: 3 லிட்டர்
- பசு பால்: 2 லிட்டர்
- பசு தயிர்: 2 லிட்டர்
- பசு நெய்: 1 கிலோ
- வாழைப்பழம்: 12 எண்கள் (பழுத்தது)
- தேங்காய் தண்ணீர்: 3 லிட்டர்
- கரும்பு சாறு / வெல்லம்: 1 கிலோ

தயாரிக்கும் முறை:
1. நெய்யையும் சாணத்தையும் நன்கு கலக்கவும் (Day 1)
2. பால், தயிர், மூத்திரம் சேர்க்கவும் (Day 2)
3. வாழைப்பழம், தேங்காய் தண்ணீர், கரும்பு சாறு சேர்க்கவும் (Day 3)
4. தினமும் காலை மாலை கலக்கவும்
5. 15 நாட்களில் தயார்!

பயன்படுத்தும் முறை:
- 3 லிட்டர் பஞ்சகவ்யா + 100 லிட்டர் தண்ணீர் = கலவை
- 15 நாட்களுக்கு ஒரு முறை தெளிக்கவும்
```

---

**படி 3: இயற்கை உரங்கள்**

**வேப்பம் பிண்ணாக்கு:**
- {ஏக்கருக்கு} {அளவு} கிலோ
- விதைக்கும் முன் நிலத்தில் கலக்கவும்

**தென்னை நாரு/மட்கு:**
- மண் வளத்தை அதிகரிக்கும்
- ஈரப்பதத்தை தக்க வைக்கும்

**பசுந்தாள் உரம்:**
- கொட்டாவரங்காணி / தவிட்டாங்காணி விதைக்கவும்
- 45 நாட்களில் உழுது மண்ணில் கலக்கவும்

**மண்புழு உரம் (Vermicompost):**
```
தயாரிக்கும் முறை:
1. தென்னை நார் / நாற்றுப்புல் — அடுக்கவும்
2. பசு சாணம் — மெல்லிய அடுக்கு
3. மண்புழு (500-1000 எண்கள்)
4. தினமும் தண்ணீர் தெளிக்கவும் (ஈரம் தேவை)
5. 45-60 நாட்களில் தயார்

பயன்படுத்தும் அளவு:
- 1 டன் / ஏக்கர் (முதல் உழுதலின் போது)
```

---

**படி 4: இயற்கை பூச்சிக்கொல்லிகள்**

**நீம் எண்ணெய் கலவை:**
```
தேவையான பொருட்கள்:
- நீம் எண்ணெய்: 50 ml
- கடலை மாவு: 10 கிராம் (ஒட்டுதலுக்கு)
- தண்ணீர்: 10 லிட்டர்

முறை:
- எல்லாவற்றையும் நன்கு கலக்கவும்
- மாலை நேரத்தில் தெளிக்கவும்
- 15 நாட்களுக்கு ஒரு முறை
```

**பூண்டு மிளகாய் கலவை:**
```
தேவை:
- பூண்டு: 100 கிராம்
- பச்சை மிளகாய்: 100 கிராம்
- சோப் நட்டு: 50 கிராம்

முறை:
1. அனைத்தையும் அரைத்து சாறு எடுக்கவும்
2. 10 லிட்டர் தண்ணீரில் கலக்கவும்
3. ஒரு இரவு ஊற வைக்கவும்
4. வடிகட்டி மாலை நேரம் தெளிக்கவும்
```

**தண்ணீர் - சோப்பு கலவை:** (இலை பூச்சிகளுக்கு)
```
- தண்ணீர்: 10 லிட்டர்
- கழுவும் சோப்பு தூள்: 10 கிராம்
- நன்கு கலந்து தெளிக்கவும்
```

---

**படி 5: நீர் நிர்வாகம்**

- துளி நீர் பாசனம் (Drip Irrigation) — சிறந்தது
- மண் ஈரம் பராமரிக்க வைக்கோல் மூடுதல் (Mulching)
- தண்ணீர் குறைவாக பயன்படுத்தவும்

---

**படி 6: களை மேலாண்மை**

- கையால் நீக்குதல் (Best!)
- வைக்கோல் / கரும்பு கசடு பரப்புதல் — களை வளராது
- பசுந்தாள் உரமாக களை பயன்படுத்தவும்

---

📊 இயற்கை vs. ரசாயன — ஒப்பீடு:

| அம்சம் | இயற்கை விவசாயம் | ரசாயன விவசாயம் |
|--------|------------------|------------------|
| ஆரம்ப செலவு | அதிகம் | குறைவு |
| நீண்ட கால செலவு | குறைவு | அதிகம் |
| மண் வளம் | மேம்படும் | குறையும் |
| மகசூல் | நடுத்தர (ஆனால் நிலையானது) | அதிகம் (ஆனால் குறையும்) |
| விலை | அதிகம் | சராசரி |
| சுற்றுச்சூழல் | பாதுகாப்பு | மாசுபடும் |
