# 👨‍👩‍👧 பெற்றோர்கள் (Parents)

> [!NOTE]
> **துறை (Domain):** தினசரி வாழ்க்கை (`daily`)
> **தரநிலை (Standard):** [தமிழ் AI கட்டளை தரநிலை](../../.agent/rules/taxonomy.md)
> **பாதுகாப்பு (Safety):** L8 அடுக்கு — குழந்தை நல நிபுணர் ஆலோசனை பரிந்துரை

இந்தத் தொகுப்பு **குழந்தைகளை வளர்க்கும் பெற்றோர்களுக்கான** AI கட்டளைகளை உள்ளடக்கியது.

## 📑 பெற்றோர் கட்டளைகள் (Parenting Prompts)

### 1️⃣ வயதுக்கேற்ற திரை நேரம் வழிகாட்டல் (Screen Time Guidance)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு குழந்தை நல ஆலோசகர். என் குழந்தைக்கு திரை நேரம் (Screen Time)
பற்றி எப்படி வழிகாட்டுவது என்று கூறு.

**குழந்தை பற்றிய தகவல்:**
- வயது: {குழந்தை வயது}
- வகை: {தொலைக்காட்சி / Tablet / Mobile / Computer}
- தினசரி நேரம்: {தற்போது எத்தனை மணி நேரம்}
- பயன்பாடு: {கல்வி / பொழுதுபோக்கு / விளையாட்டு}

**எனக்கு தேவையானது:**
- வயதுக்கேற்ற திரை நேர வரம்பு (WHO / AAP பரிந்துரை)
- திரை நேரத்தை சுவாரசியமாக குறைக்கும் வழிகள்
- மாற்று செயல்பாடுகள் (3-4 யோசனைகள்)
- எப்போது கவலைப்பட வேண்டும்?

**மொழி:** எளிய தமிழில், நடைமுறை ஆலோசனை
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```prompt
📱 திரை நேரம் — வழிகாட்டல்

🎯 வயதுக்கேற்ற வரம்பு:
{வயது வாரியாக பரிந்துரை}

✅ குறைக்கும் வழிகள்:
1. {வழி 1}
2. {வழி 2}
3. {வழி 3}

🎮 மாற்று செயல்பாடுகள்:
- {செயல்பாடு 1}
- {செயல்பாடு 2}

⚠️ கவலைப்பட வேண்டிய அறிகுறிகள்:
{அறிகுறி பட்டியல்}
```

**L8 பாதுகாப்பு:**

```prompt
⚠️ குழந்தை வளர்ப்பு அறிவிப்பு:
இவை பொது வழிகாட்டல்கள் மட்டுமே.
குழந்தையின் நடத்தை, மனநலம் சார்ந்த
கவலைகளுக்கு குழந்தை மனநல நிபுணரை அணுகவும்.
```

### 2️⃣ குழந்தைகளுக்கு ஆரோக்கியமான பழக்கங்கள் கற்றுக்கொடுத்தல் (Teaching Healthy Habits)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு குழந்தை வளர்ப்பு நிபுணர். என் குழந்தைக்கு {பழக்கம்} என்ற
நல்ல பழக்கத்தை கற்றுக்கொடுக்க எப்படி அணுகுவது என்று கூறு.

**குழந்தை பற்றிய தகவல்:**
- வயது: {வயது}
- தற்போதைய நிலைமை: {பழக்கம் இல்லை / சில நேரம் செய்கிறது / முரண்படுகிறது}

**கற்றுக்கொடுக்க வேண்டிய பழக்கங்கள் (ஏதேனும் ஒன்று):**
- பல் தேய்ப்பது (Brushing Teeth)
- கை கழுவுதல் (Handwashing)
- சரியான நேரத்தில் தூங்குவது (Sleep Routine)
- காய்கறி சாப்பிடுவது (Eating Vegetables)
- ஒழுங்காக இருப்பது (Tidiness)

**கோரிக்கை:**
- குழந்தைக்கு சுவாரசியமான முறை
- படிப்படியான அணுகுமுறை
- பெற்றோர் என்ன செய்ய வேண்டும்?
- எவ்வளவு நாள் ஆகும்?
```

**L8 பாதுகாப்பு:**

```prompt
📌 குறிப்பு: குழந்தை தொடர்ந்து மறுத்தால் அல்லது
கடுமையான நடத்தை மாற்றம் இருந்தால்
குழந்தை நல மருத்துவரை அணுகவும்.
```

### 3️⃣ படிக்க மறுக்கும் குழந்தையை ஊக்குவித்தல் (Motivating a Child Who Refuses to Study)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு கல்வி ஆலோசகர். என் {வயது} வயது குழந்தை படிக்க மறுக்கிறது /
படிப்பில் ஆர்வம் இல்லை. இதை எப்படி கையாள்வது என்று கூறு.

**தற்போதைய நிலைமை:**
- வகுப்பு: {வகுப்பு எண்}
- மறுக்கும் பாடம்: {பாடம் அல்லது அனைத்தும்}
- காரணம் (தெரிந்தால்): {எ.கா., கஷ்டமாக உள்ளது / நண்பர்கள் பிரச்சினை / ஆசிரியர் பிரச்சினை}
- படிப்பு நேரம்: {எத்தனை மணி நேரம்}

**எனக்கு தேவையானது:**
1. உடனடி நடவடிக்கைகள் (5 யோசனைகள்)
2. நீண்ட கால உத்திகள்
3. பெற்றோர் என்ன தவறு செய்யக்கூடாது?
4. ஆசிரியருடன் எப்படி பேசுவது?
```

**L8 பாதுகாப்பு:**

```prompt
⚠️ குழந்தை திடீரென்று படிப்பில் ஆர்வம் இழந்தால்
அல்லது தொடர்ந்து கஷ்டப்பட்டால்,
கற்றல் குறைபாடு (Learning Disability) இருக்கலாம்.
குழந்தை மனநல / கல்வி நிபுணரை அணுகவும்.
```

### 4️⃣ உணர்ச்சி திறன் வளர்ப்பு — அழும் குழந்தையை கையாளுதல் (Emotional Intelligence - Handling a Crying Child)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு குழந்தை உளவியல் நிபுணர். என் குழந்தை (வயது: {வயது})
அடிக்கடி அழுகிறது / கோபப்படுகிறது / சின்னவிஷயத்திற்கு விம்மிட்டு அழுகிறது.
இதை எப்படி கையாள்வது என்று கூறு.

**சூழல்:**
- நிகழும் நேரம்: {பள்ளியில் / வீட்டில் / பொது இடங்களில்}
- தூண்டுகோல்: {என்ன காரணத்தால்}
- வழக்கமான நடத்தை: {சாதாரணமாக எப்படி}

**வழிகாட்டல் தேவை:**
1. உடனடி சூழலில் எப்படி பதிலளிப்பது?
2. குழந்தையுடன் பின்னர் எப்படி பேசுவது?
3. உணர்ச்சி மேலாண்மை கற்றுக்கொடுக்கும் செயல்பாடுகள்
4. தவிர்க்க வேண்டியவை என்ன?
```

**L8 பாதுகாப்பு:**

```prompt
⚠️ குழந்தை தொடர்ந்து கஷ்டப்பட்டால்,
சாப்பிட மறுத்தால், தூக்கம் வரவில்லை என்றால்,
குழந்தை மனநல நிபுணரை உடனே அணுகவும்.
```

### 5️⃣ குழந்தைக்கு பணம் பற்றிய புரிதல் (Teaching Money Management to Children)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு நிதி கல்வி நிபுணர். {வயது} வயது குழந்தைக்கு
பணம் பற்றிய புரிதல் (Financial Literacy) கற்றுக்கொடுக்க
வயதுக்கேற்ற வழிகளை கூறு.

**தலைப்புகள் (ஏதேனும் ஒன்று):**
- சேமிப்பு என்றால் என்ன? (What is Saving?)
- தேவை vs விருப்பம் (Need vs Want)
- கைச்செலவு (Pocket Money) மேலாண்மை
- கொடுப்பதன் மகிழ்ச்சி (Joy of Giving)
- வங்கி என்றால் என்ன?

**விளக்கும் முறை:**
- வயதுக்கேற்ற எடுத்துக்காட்டுகள்
- செயல்பாட்டு யோசனைகள் (Activities)
- கதை வழி கற்றல் (Story-Based Learning)

**வடிவம்:** பெற்றோர் வழிகாட்டல் + குழந்தைக்கு நேரடி விளக்கம்
```

**L8 பாதுகாப்பு:**

```prompt
📌 இது நிதி ஆலோசனை அல்ல.
குழந்தைகளுக்கான நிதி கல்வி நோக்கில் மட்டும்.
```

### 6️⃣ குழந்தை ஆன்லைன் பாதுகாப்பு (Child Online Safety)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு டிஜிட்டல் பாதுகாப்பு நிபுணர். {வயது} வயது குழந்தை
இணையம் / சமூக ஊடகம் பயன்படுத்துகிறது.
பெற்றோர்களாக நாங்கள் என்ன கவனிக்க வேண்டும்?

**தகவல்:**
- பயன்படுத்தும் தளங்கள்: {YouTube / Instagram / Games / WhatsApp}
- தினசரி நேரம்: {எத்தனை மணி நேரம்}
- மேற்பார்வை: {மிகவும் கவனிக்கிறோம் / சில நேரம் / இல்லை}

**தேவை:**
1. வயதுக்கேற்ற இணைய பயன்பாடு வரம்புகள்
2. கண்காணிப்பு கருவிகள் (Parental Controls) — இலவசமானவை
3. குழந்தையுடன் ஆன்லைன் பாதுகாப்பு பேசும் முறை
4. ஆபத்தான அறிகுறிகள் (Red Flags) என்ன?
5. Cyberbullying என்றால் என்ன? என்ன செய்வது?
```

**L8 பாதுகாப்பு:**

```prompt
🛡️ குழந்தை ஆன்லைன் துன்புறுத்தல் / தொல்லைக்கு ஆளானால்:
✓ குழந்தையை நம்பு, குற்றம் கூறாதே
✓ evidence சேர் (screenshot)
✓ பள்ளி / காவல்துறை அணுகு
✓ Cybercrime: 1930 (தேசிய இணைய குற்றம் helpline)
```

### 7️⃣ குழந்தைகளுக்கு தமிழ் கற்றுக்கொடுத்தல் (Teaching Tamil to Children)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு தமிழ் ஆசிரியர். என் {வயது} வயது குழந்தைக்கு வீட்டிலேயே
தமிழை சுவாரசியமாக கற்றுக்கொடுக்க என்ன செய்யலாம்?

**தற்போதைய நிலை:**
- தமிழ் பேச: {நன்றாக / சிறிது / இல்லை}
- தமிழ் படிக்க: {நன்றாக / சிறிது / இல்லை}
- தமிழ் எழுத: {நன்றாக / சிறிது / இல்லை}
- குழந்தைக்கு ஆர்வம்: {உண்டு / இல்லை / சில நேரம்}

**அணுகுமுறை (ஏதேனும் ஒன்று):**
- தினசரி 10 நிமிட பயிற்சி
- விளையாட்டு மூலம் கற்றல்
- தமிழ் படங்கள் / கதைகள் மூலம்
- தமிழ் பாடல்கள் மூலம்

**எதிர்பார்ப்பு:** 30 நாள் திட்டம்
```

### 8️⃣ பெற்றோர்-குழந்தை உறவு மேம்பாடு (Improving Parent-Child Bond)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு குடும்ப ஆலோசகர். என் குழந்தை (வயது: {வயது}) என்னிடம்
திறந்து பேசவில்லை / என்னை புரிந்துகொள்வதில்லை என்று உணர்கிறேன்.
உறவை மேம்படுத்த என்ன செய்யலாம்?

**சூழல்:**
- குழந்தை பொதுவாக: {வெளிப்படையான / உள்முக / அமைதியான}
- தகவல்தொடர்பு: {நன்றாக பேசுகிறோம் / குறைவாக / பிரச்சினை}
- பிரச்சினை தொடங்கியது: {சமீபத்தில் / எப்போதுமே}

**தேவை:**
1. தினசரி உறவை பலப்படுத்தும் சின்ன செயல்கள்
2. குழந்தையிடம் பேசும் முறை (Active Listening)
3. தவிர்க்க வேண்டியவை
4. வாரம் ஒரு முறை செய்யக்கூடிய குடும்ப செயல்பாடுகள்
```

### 9️⃣ குழந்தைக்கு சாப்பிட வைத்தல் — ஊட்டச்சத்து (Getting Children to Eat Healthy)

**கட்டளை (Prompt):**


### AI பெற்றோர் உதவிக்கு எப்படி பயன்படுத்துவது:

- 🎯 **நடைமுறை:** AI சொல்வதை அப்படியே செய்யாதீர்கள் — உங்கள் குழந்தையை நீங்கள் நன்கு அறிவீர்கள்
- 📚 **கற்றல்:** கட்டுரைகள், புத்தகங்கள் படிக்க AI உதவும்
- 🤝 **ஆதரவு:** மற்ற பெற்றோர்களுடன் பேசுங்கள் — AI மட்டுமே நம்பாதீர்கள்
