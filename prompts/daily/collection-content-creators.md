### 1️⃣ YouTube Video Script (YouTube வீடியோ ஸ்கிரிப்ட்)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு தமிழ் YouTube Script Writer. என் சேனலுக்கு
ஒரு engaging video script எழுது.

**வீடியோ பற்றிய தகவல்:**
- சேனல் வகை: {Education / Entertainment / Vlog / Tech / Cooking / Finance / Health}
- தலைப்பு / யோசனை: {உங்கள் வீடியோ தலைப்பு}
- இலக்கு பார்வையாளர்கள்: {யாருக்கு — வயது, ஆர்வம்}
- வீடியோ நேரம்: {5 நிமிடம் / 10 நிமிடம் / 15+ நிமிடம்}
- தொனி: {Casual / Educational / Entertaining / Motivational}
- மொழி: {தமிழ் மட்டும் / Tanglish / தமிழ் with English terms}

**Script கட்டமைப்பு:**
1. Hook (0-30 seconds) — பார்வையாளரை கவரும் தொடக்கம்
2. Introduction — சேனல் & தலைப்பு அறிமுகம்
3. Main Content — பிரிவுகளாக (Sections)
4. Engagement Points — Comment கேளும் இடங்கள்
5. Call-to-Action — Like, Subscribe, Share
6. Outro — அடுத்த வீடியோ teaser

**கூடுதல் தேவைகள்:**
- B-Roll suggestions (என்ன காட்சிகள் எடுக்கலாம்)
- On-screen text (என்ன எழுத்துகள் காட்டலாம்)
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```prompt
🎬 "{வீடியோ தலைப்பு}" — Script

━━━━━━━━━━━━━━━━━━━━
🎯 HOOK (0:00 - 0:30)
━━━━━━━━━━━━━━━━━━━━
[ON CAMERA]
"{attention-grabbing opening line}"

[B-ROLL: {என்ன காட்சி}]

━━━━━━━━━━━━━━━━━━━━
📌 INTRO (0:30 - 1:00)
━━━━━━━━━━━━━━━━━━━━
[ON CAMERA]
"வணக்கம் {சேனல் பெயர்}க்கு வருக..."

[TEXT ON SCREEN: {முக்கிய புள்ளி}]

━━━━━━━━━━━━━━━━━━━━
📚 SECTION 1: {தலைப்பு}
━━━━━━━━━━━━━━━━━━━━
...
```

**L8 பாதுகாப்பு:**

```prompt
📜 Content Creator பாதுகாப்பு:
✓ Copyright உள்ள இசை / images பயன்படுத்தாதீர்கள்
✓ YouTube Community Guidelines பின்பற்றவும்
✓ Health / Finance advice script-ல் disclaimer சேர்க்கவும்
✓ குழந்தைகளுக்கான சேனல் — COPPA விதிகள் கவனிக்கவும்
```

### 2️⃣ YouTube Title & Description (தலைப்பு & விவரணம்)

**கட்டளை (Prompt):**

```prompt
நீ ஒரு YouTube SEO நிபுணர். என் வீடியோவிற்கு
click-worthy title மற்றும் SEO-optimized description எழுது.

**வீடியோ பற்றி:**
- விஷயம்: {வீடியோ என்னவாக இருக்கும்}
- Target audience: {யாருக்கு}
- Keywords: {முக்கியமான தேடல் வார்த்தைகள் — 3-5}
- மொழி: {தமிழ் / Tamil + English}

**தேவை:**
1. Title options — 5 வகைகள்:
   - Curiosity gap title (호기심 format)
   - Number-based title (listicle)
   - How-to title
   - Problem-solution title
   - Emotional hook title

2. Description (தமிழ் / ஆங்கிலம்):
   - First 150 characters (மிக முக்கியம் — search-ல் தெரியும்)
   - Full description (500 வார்த்தைகள்)
   - Timestamps
   - Related links
   - Social media links placeholder
   - Hashtags (15-20)

3. Tags (20-30 tags)
```

**எதிர்பார்க்கப்படும் வடிவம்:**

```prompt
📌 TITLE OPTIONS:

Option 1 (Curiosity): "{title}"
Option 2 (Number): "{title}"
Option 3 (How-to): "{title}"
Option 4 (Problem-Solution): "{title}"
Option 5 (Emotional): "{title}"

🏆 Recommended: Option {number} — ஏன்: {சுருக்கமான காரணம்}

━━━━━━━━━━━━━━━━━━━━
📝 DESCRIPTION:
━━━━━━━━━━━━━━━━━━━━

{First 150 chars — search snippet}

{Full description}

⏱️ TIMESTAMPS:
0:00 - Introduction
{மற்ற timestamps}

🔗 LINKS:
{Related videos / playlists}

#tags
```

## 🎬 Content Creators-க்கான குறிப்புகள்

### AI-ஐ Content Creation-ல் பயன்படுத்துவது:

- 💡 **யோசனை** — AI பல options தரும், உங்கள் voice-ல் மாற்றவும்
- ✍️ **Draft** — AI எழுதுவது starting point மட்டும், edit கட்டாயம்
- 🔍 **Research** — facts verify செய்யவும், AI தவறு செய்யலாம்
- 🎯 **Consistency** — உங்கள் brand voice மாறாமல் பாதுகாக்கவும்

### AI-ஐ நேர்மையாக பயன்படுத்துங்கள்:

- ✅ AI tools பயன்படுத்தியதை audience-இடம் மறைக்க வேண்டாம்
- ✅ உங்கள் சொந்த ideas & personality — AI-யை விட மதிப்புமிக்கது
- ✅ Fact-check எல்லாவற்றையும் — AI hallucination possible

**L8 பாதுகாப்பு அறிவிப்பு:**

```prompt
🎬 Content Creator பாதுகாப்பு அறிவிப்பு:

இந்தத் தகவல்கள் கல்வி மற்றும் உள்ளடக்க உருவாக்கம்
நோக்கத்திற்காக மட்டுமே.

✓ Copyright இல்லாத இசை / images பயன்படுத்தவும்
✓ YouTube / Meta Community Guidelines பின்பற்றவும்
✓ Sponsored content-க்கு disclosure கட்டாயம்
✓ Health, Finance, Legal claims-க்கு disclaimer சேர்க்கவும்
✓ AI-generated content-ஐ label செய்வது நல்லது
✓ குழந்தைகளை feature செய்யும்போது பெற்றோர் அனுமதி கட்டாயம்

Reporting:
```
