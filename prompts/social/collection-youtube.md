### 1️⃣ வீடியோ தலைப்பு (SEO)

> [!PROMPT]
> நீ ஒரு தமிழ் YouTube SEO நிபுணர். கீழ்க்கண்ட வீடியோவுக்கு தேடல் நோக்கில் சிறந்த தலைப்புகளை உருவாக்கு.
>
> **வீடியோ பற்றி:**
> - பொருள்: {வீடியோவின் முக்கிய கருத்து}
> - சேனல் வகை: {கல்வி / சமையல் / தொழில்நுட்பம் / நகைச்சுவை / செய்தி / தனிப்பட்ட / கலை}
> - இலக்கு பார்வையாளர்: {வயது, ஆர்வம், அறிவு நிலை}
> - மொழி கலவை: {தமிழ் மட்டும் / Tanglish / தமிழ் + ஆங்கில Terms}
>
> **10 தலைப்புகள் தா — வேறு வேறு வகைகளில்:**
>
> | # | தலைப்பு | வகை | ஏன் வேலை செய்யும் |
> |---|---------|-----|-----------------|
> | 1 | | கேள்வி வடிவம் | |
> | 2 | | எண் பட்டியல் | |
> | 3 | | "இப்படி செய்யாதே" | |
> | 4 | | "நான் கற்றுக்கொண்டேன்" | |
> | 5 | | அதிர்ச்சி / ஆச்சரியம் | |
> | 6 | | "முதல்முறை" | |
> | 7 | | SEO-direct | |
> | 8 | | உணர்வுப்பூர்வம் | |
> | 9 | | நேர அழுத்தம் | |
> | 10 | | உள்ளூர் / Tamil-specific | |
>
> ஒவ்வொரு தலைப்பும் 60 எழுத்துகளுக்கு உட்பட்டு இருக்கட்டும்.

**பயன்பாடு:** வீடியோ upload செய்வதற்கு முன் சிறந்த தலைப்பு தேர்வு செய்ய.

### 2️⃣ வீடியோ விளக்கம்

> [!PROMPT]
> YouTube வீடியோவுக்கான SEO விளக்கம் (Description) எழுது.
>
> **வீடியோ தகவல்கள்:**
> - தலைப்பு: {வீடியோ தலைப்பு}
> - முக்கிய கருத்துகள்: {3-5 புள்ளிகளில் என்ன பேசுகிறீர்கள்}
> - சேனல் பெயர்: {பெயர்}
> - முக்கிய Keywords: {3-5 சொற்கள்}
> - தொடர்பு / Social media: {இணைப்புகள் placeholder}
>
> **விளக்க கட்டமைப்பு:**
>
> **பகுதி 1 — முதல் 2 வரிகள் (Thumbnail-க்கு கீழே தெரிவது):**
> வீடியோவின் சாரத்தை கவரும் வகையில் — keyword-rich
>
> **பகுதி 2 — வீடியோ சுருக்கம்:**
> 3-4 வாக்கியங்களில் என்ன கற்றுக்கொள்வார்கள்
>
> **பகுதி 3 — நேர முத்திரைகள் (Timestamps):**
> 00:00 - அறிமுகம்
> {நேர முத்திரை placeholder-கள்}
>
> **பகுதி 4 — சமூக ஊடக இணைப்புகள் & CTA:**
> Subscribe / Instagram / Website இணைப்புகள்
>
> **பகுதி 5 — Hashtags (கடைசி வரியில்):**
> #தமிழ் #{keyword1} #{keyword2}

**பயன்பாடு:** YouTube search-ல் வீடியோ கண்டுபிடிக்கப்பட வாய்ப்பை அதிகரிக்கும்.

### 3️⃣ Tags & Keywords

> [!PROMPT]
> YouTube வீடியோவுக்கான Tags பட்டியல் உருவாக்கு.
>
> **வீடியோ பொருள்:** {தலைப்பு / கருத்து}
> **சேனல் துறை:** {கல்வி / சமையல் / சுகாதாரம் / தொழில்நுட்பம் / பொழுதுபோக்கு}
>
> **பட்டியல் வடிவம்:**
>
> | வகை | Tags |
> |-----|------|
> | சரியான பொருள் (Exact) | {தலைப்பு keywords} |
> | பரந்த வகை (Broad) | {துறை keywords} |
> | தமிழ் Tags | {தமிழ் சொற்கள்} |
> | Tanglish Tags | {கலந்த சொற்கள்} |
> | ஆங்கில Tags | {English keywords} |
> | போட்டியாளர் சேனல் Tags | {பிரபல சேனல் பெயர்கள்} |
> | கேள்வி Tags | {how to, என்ன, எப்படி} |
>
> மொத்தம் 30-40 Tags — கல்பையை (comma) கொண்டு பிரித்து தா.

**பயன்பாடு:** YouTube Studio → Tags பகுதியில் நேரடியாக ஒட்டலாம்.

### 4️⃣ Thumbnail கான்செப்ட்

> [!PROMPT]
> YouTube Thumbnail-க்கான கான்செப்ட் மற்றும் AI Image Prompt உருவாக்கு.
>
> **வீடியோ விவரம்:**
> - தலைப்பு: {வீடியோ தலைப்பு}
> - சேனல் தொனி: {தீவிரம் / நகைச்சுவை / கல்வி / ஊக்கமூட்டுதல் / செய்தி}
> - முக்கிய உணர்வு: {ஆச்சரியம் / கோபம் / ஆர்வம் / சந்தோஷம் / அதிர்ச்சி}
>
> **வழங்க வேண்டியவை:**
>
> **1. Thumbnail கான்செப்ட் (மனித விளக்கம்):**
> - பின்னணி நிறம் / காட்சி
> - முகவுடைய நபர் — உணர்வு, நிலை
> - உரை (Text) — என்ன எழுத்துகள், எங்கே
> - முக்கிய கவனத்தை ஈர்க்கும் பொருள்
>
> **2. Canva / Photoshop-க்கு Text Layout:**
> - Main text: {பெரிய எழுத்துகளில் என்ன}
> - Sub text: {சிறிய எழுத்துகளில் என்ன}
> - Font style: {Bold / Outline / Shadow}
>
> **3. AI Image Generator Prompt (Midjourney / Flux):**
> {AI-க்கு கொடுக்கும் ஆங்கில prompt}
>
> Thumbnail அளவு: 1280 × 720 px, 72 DPI

**பயன்பாடு:** வீடியோ thumbnail-ஐ AI கருவிகள் மூலம் உருவாக்க.

### 5️⃣ YouTube Shorts ஸ்கிரிப்ட்

> [!PROMPT]
> 60 வினாடி YouTube Shorts-க்கான ஸ்கிரிப்ட் எழுது.
>
> **விவரங்கள்:**
> - கருத்து / யோசனை: {Shorts-ன் பொருள்}
> - வகை: {கல்வி / நகைச்சுவை / ஊக்கமூட்டுதல் / செய்தி / சமையல் / தொழில்நுட்பம்}
> - மொழி: {தமிழ் / Tanglish}
>
> **ஸ்கிரிப்ட் கட்டமைப்பு:**
>
> **[0:00-0:03] HOOK — கவரும் தொடக்கம்**
> {கேள்வி / அதிர்ச்சி தகவல் / "பாருங்கள்" ஆரம்பம்}
>
> **[0:03-0:45] முக்கிய உள்ளடக்கம்**
> {3-4 வேகமான புள்ளிகளில்}
>
> **[0:45-0:60] முடிவு + CTA**
> {Like / Subscribe / இன்னொரு Shorts பாருங்கள்}
>
> **On-screen Text (திரையில் காட்ட):**
> {ஒவ்வொரு நொடிக்கும் என்ன காட்ட}
>
> குறிப்பு: Shorts-ல் பேசும் வேகம் அதிகமாக இருக்கும் — வார்த்தைகள் சுருக்கமாக இருக்கட்டும்.

**பயன்பாடு:** நீண்ட வீடியோவிலிருந்து Shorts அல்லது தனியான Shorts content.

### 6️⃣ சேனல் அறிமுகம் (About)

> [!PROMPT]
> YouTube சேனல் About பகுதிக்கான விளக்கம் எழுது.
>
> **சேனல் விவரங்கள்:**
> - சேனல் பெயர்: {பெயர்}
> - வகை: {கல்வி / பொழுதுபோக்கு / செய்தி / சமையல் / தொழில்நுட்பம் / கலை / வாழ்க்கை முறை}
> - யாருக்காக: {இலக்கு பார்வையாளர்}
> - எத்தனை நாளில் / வாரத்தில் வீடியோ வெளியிடுவீர்கள்: {அட்டவணை}
> - சேனல் தொடங்கிய காரணம் / தொடர்பு: {ஒரு வரியில்}
>
> **வழங்க வேண்டியவை:**
> 1. தமிழ் விளக்கம் (250-300 வார்த்தைகள்) — keyword-rich
> 2. ஆங்கில விளக்கம் (150 வார்த்தைகள்) — SEO-க்காக
> 3. Channel Tagline (ஒரே வரியில் சேனல் சாரம்)
>
> பார்வையாளர் "Subscribe" செய்ய தூண்டும் வகையில் எழுது.

**பயன்பாடு:** YouTube Studio → Customization → Basic Info → Description.

### 7️⃣ சமுதாயப் பதிவு

> [!PROMPT]
> YouTube Community Tab-ல் பதிவிட ஒரு இடுகை எழுது.
>
> **பதிவு வகை:**
> - {கேள்வி (Poll) / அறிவிப்பு / பின்னணி தகவல் (Behind-the-scenes) / நன்றி / கருத்துக் கேட்கை / Teaser}
>
> **விவரங்கள்:**
> - என்ன சொல்ல விரும்புகிறீர்கள்: {கருத்து}
> - பார்வையாளருடன் என்ன தொடர்பு ஏற்படுத்தணும்: {கமெண்ட் / Poll வாக்கு / Like}
>
> **வழிகாட்டுதல்கள்:**
> - 150 வார்த்தைகளுக்கு உட்பட்டு
> - Community-ல் பேசுவது போல் — சேனல் மொழியில்
> - கமெண்ட் அழைப்பு (CTA) கட்டாயம் சேர்
>
> Poll வகையாக இருந்தால் 2-4 விருப்பங்கள் தா.

**பயன்பாடு:** வீடியோ இல்லாத நாட்களில் பார்வையாளரை engaged வைக்க.

### 8️⃣ Playlist விளக்கம்

> [!PROMPT]
> YouTube Playlist-க்கான பெயர் மற்றும் விளக்கம் எழுது.
>
> **Playlist பற்றி:**
> - தொடர் தலைப்பு: {தொடரின் பொருள்}
> - வீடியோக்களின் எண்ணிக்கை: {எத்தனை வீடியோ}
> - பார்வையாளர் யாரிடமிருந்து தொடங்கி எங்கு போவார்கள்: {தொடக்க நிலை → இறுதி நிலை}
>
> **வழங்க வேண்டியவை:**
> 1. Playlist பெயர்கள் (3 விருப்பங்கள்) — SEO-நட்பான
