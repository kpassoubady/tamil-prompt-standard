### 1️⃣ Hook — முதல் 3 வினாடி

> [!PROMPT]
> என் குறும் வீடியோவுக்கு கவரும் Hook (முதல் 3 வினாடி) எழுது.
>
> **வீடியோ பொருள்:** {என்ன சொல்ல விரும்புகிறீர்கள்}
> **வகை:** {கல்வி / நகைச்சுவை / ஊக்கம் / தயாரிப்பு / செய்தி}
> **இலக்கு பார்வையாளர்:** {யார்}
>
> **10 Hook பதிப்புகள் தா — வேறு வேறு உத்திகளில்:**
>
> | # | Hook | உத்தி | ஏன் scroll நிறுத்தும் |
> |---|------|-------|---------------------|
> | 1 | | கேள்வி | |
> | 2 | | எதிர்மறை / "இதை செய்யாதே" | |
> | 3 | | "யாருக்கும் சொல்லவில்லை" | |
> | 4 | | எண் / List | |
> | 5 | | அதிர்ச்சி தகவல் | |
> | 6 | | உடனடி பலன் | |
> | 7 | | "நீங்கள் இதை செய்கிறீர்களா?" | |
> | 8 | | நேரக்கட்டுப்பாடு | |
> | 9 | | அடையாளம் (Relatability) | |
> | 10 | | சவால் | |
>
> On-screen text overlay (முதல் frame-ல் காட்ட): {பரிந்துரை}

**பயன்பாடு:** Hook தான் Reel-ல் மிக முக்கியமான பகுதி — scroll நிறுத்துகிறதா இல்லையா என்பதை தீர்மானிக்கும்.

>

> - கருத்து: {என்ன கற்பிக்கிறீர்கள்}
> - நேரம்: {30 வின் / 60 வின் / 90 வின்}
> - பார்வையாளர்: {மாணவர் / பொதுமக்கள் / தொழில்முறை}
> - மொழி: {தமிழ் / Tanglish}
>
> **ஸ்கிரிப்ட் கட்டமைப்பு:**
>
> **[Hook - 0:00-0:03]**
> {கவரும் தொடக்கம்}
>
> **[பிரச்சினை - 0:03-0:10]**
> {ஏன் இது முக்கியம்}
>
> **[தீர்வு - 0:10-0:45]**
> {3 வேகமான Points}
>
> **[முடிவு - 0:45-0:60]**
> {சுருக்கம் + Save/Share CTA}
>
> **On-screen Text Overlay:** ஒவ்வொரு நொடிக்கும்
> **Voiceover / OC (On Camera):** எந்த பகுதியில் என்ன பேசுவீர்கள்

**பயன்பாடு:** ஆசிரியர்கள், நிபுணர்கள், தகவல் creator-களுக்கு.
