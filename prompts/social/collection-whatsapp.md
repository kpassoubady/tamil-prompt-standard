# 💬 WhatsApp தொடர்பாடல்

> [!NOTE]
> **துறை (Domain):** சமூக ஊடகம் (`social`)
> **தரநிலை (Standard):** [தமிழ் AI கட்டளை தரநிலை](../../.agent/rules/taxonomy.md)
> **பாதுகாப்பு (Safety):** L8 அடுக்கு — தனியுரிமை, Spam தவிர்ப்பு, Broadcast விதிமுறைகள்

தனிநபர்கள், குழு நிர்வாகிகள், சிறு வியாபாரிகள், சமூக அமைப்புகள் — WhatsApp வழியாக தெளிவாகவும் கண்ணியமாகவும் தொடர்புகொள்ள உதவும் கட்டளைகள்.

### 1️⃣ தனிப்பட்ட செய்தி வடிவமைப்பு

> [!PROMPT]
> நீ ஒரு தமிழ் மொழி ஆலோசகர். கீழ்க்கண்ட சூழ்நிலைக்கு ஒரு WhatsApp செய்தி எழுது.
>
> **சூழ்நிலை விவரங்கள்:**
> - செய்தி வகை: {உதவி கேட்பது / நன்றி தெரிவிப்பது / மன்னிப்பு கேட்பது / தகவல் அனுப்புவது / ஆலோசனை கேட்பது}
> - யாருக்கு: {நண்பர் / மூத்தவர் / ஆசிரியர் / அலுவலக சக்கிராதி / குடும்பத்தினர்}
> - பொருள்: {செய்தியின் முக்கிய கருத்து}
> - தொனி: {அன்பான / மரியாதையான / நேரடியான / சற்று முறையான}
> - நீளம்: {3-4 வரி / 1 பத்தி / விரிவான}
>
> **வழிகாட்டுதல்கள்:**
> - WhatsApp formatting பயன்படுத்து (*bold*, *italic* தேவைப்பட்டால்)
> - Emoji சேர் (சேர்க்கவேண்டாம் என்றால் குறிப்பிடு)
> - இயற்கையான தமிழில் எழுது — அகராதி தமிழ் வேண்டாம்

**பயன்பாடு:** வழக்கமான WhatsApp செய்திகளை சரியான தொனியில் அனுப்ப.

### 2️⃣ Broadcast அறிவிப்பு

> [!PROMPT]
> நீ ஒரு தகவல் தொடர்பு நிபுணர். WhatsApp Broadcast list-க்கு ஒரு அறிவிப்பு செய்தி எழுது.
>
> **தகவல்கள்:**
> - அமைப்பு / குழு வகை: {கல்வி நிறுவனம் / வணிக நிறுவனம் / NGO / கோயில் கமிட்டி / அரசியல் அமைப்பு / குடியிருப்பு சங்கம்}
> - அறிவிப்பு வகை: {நிகழ்வு / மாற்றம் / எச்சரிக்கை / நன்றி / புதிய சேவை}
> - முக்கிய தகவல்: {என்ன, எப்போது, எங்கே, யாரால்}
> - செய்தி பெறுவோர்: {உறுப்பினர்கள் / வாடிக்கையாளர்கள் / மாணவர்கள் / பொதுமக்கள்}
>
> **வடிவம்:**
> - தலைப்பு வரி (Attention-grabbing)
> - முக்கிய தகவல் (2-3 புள்ளிகளில்)
> - தெளிவான CTA (என்ன செய்யவேண்டும்)
> - தொடர்பு விவரம்: {போன் / இணைப்பு / முகவரி}
>
> 160 வார்த்தைகளுக்கு உட்பட்டு எழுது. Spam போல் தெரியாமல் இயற்கையாக இரு.

**பயன்பாடு:** அமைப்புகள், கடைகள், சங்கங்கள் செய்யும் mass அறிவிப்புகளுக்கு.

### 3️⃣ குழு வரவேற்பு செய்தி

> [!PROMPT]
> ஒரு WhatsApp குழுவுக்கு புதியவர் சேரும்போது அனுப்பும் வரவேற்பு செய்தி எழுது.
>
> **குழு விவரங்கள்:**
> - குழு பெயர்: {குழுவின் பெயர்}
> - குழு நோக்கம்: {என்ன விஷயம் பேசுவார்கள்}
> - உறுப்பினர்கள்: {யார் இருக்கிறார்கள் — ஊழியர்கள், மாணவர்கள், குடும்பம், தொழில்முறையினர்}
> - தொனி: {அன்பான / தொழில்முறை / சாதாரண}
>
> **சேர்க்க வேண்டியவை:**
> - வரவேற்பு வாழ்த்து
> - குழுவின் சுருக்கமான நோக்கம்
> - முக்கிய விதிமுறைகள் (2-3 மட்டும்)
> - "கேள்வி இருந்தால் DM அனுப்புங்கள்" வகையான வரி

**பயன்பாடு:** குழு admin-கள் புதிய உறுப்பினர்களை வரவேற்க.

### 4️⃣ குழு விதிமுறைகள்

> [!PROMPT]
> ஒரு WhatsApp குழுவுக்கான விதிமுறைகள் (Group Rules) எழுது.
>
> **குழு வகை:** {குடும்ப குழு / ஆசிரியர்-மாணவர் குழு / வணிக குழு / அரசியல் குழு / பொது நலன் குழு}
> **உறுப்பினர் எண்ணிக்கை:** {சிறிய (<20) / நடுத்தரம் (20-100) / பெரியது (100+)}
> **முக்கிய சவால்கள்:** {Spam / தவறான தகவல் / வெளிப்பட்ட பொருள் / அரசியல் சண்டை / விளம்பரங்கள்}
>
> **வடிவம்:**
> - 📌 என்ற தலைப்பு
> - எண் இட்ட விதிமுறைகள் (5-8 மட்டும் — அதிகமாக வேண்டாம்)
> - ஒவ்வொரு விதியும் ஒரு வரியில் — தெளிவாக, கோபமின்றி
> - கடைசியில் "மீறினால்" விளைவு — கண்ணியமான மொழியில்

**பயன்பாடு:** குழுவை ஒழுங்காக நடத்த Pinned message ஆக பயன்படுத்தலாம்.

### 5️⃣ WhatsApp Status உரை

> [!PROMPT]
> WhatsApp Status-க்கு ஒரு சிறு உரை எழுது.
>
> **வகை:**
> - {தனிப்பட்ட எண்ணம் / ஊக்கமளிக்கும் மேற்கோள் / அன்றைய திட்டம் / சிரிக்கும் நகைச்சுவை / ஆன்மீக சிந்தனை / வியாபார அறிவிப்பு}
>
> **தொனி:** {தமிழ் மட்டும் / Tanglish / காவியத் தமிழ் / நகைச்சுவை}
> **நீளம்:** 700 எழுத்துகளுக்கு உட்பட்டு
>
> 3 வேறுபட்ட வகைகள் தா — ஒவ்வொன்றும் வேறு கோணத்தில்.

**பயன்பாடு:** தினசரி அல்லது வாராந்திர Status புதுப்பிப்புகளுக்கு.

### 6️⃣ விழா வாழ்த்துகள்

> [!PROMPT]
> {விழா/நிகழ்வு} க்கான WhatsApp வாழ்த்து செய்தி எழுது.
>
> **விழா:** {பொங்கல் / தீபாவளி / ஈஸ்டர் / ஈத் / பிறந்தநாள் / திருமண ஆண்டு விழா / பட்டம் பெற்ற நாள் / புத்தாண்டு}
> **யாருக்கு:** {நண்பர் / குடும்பம் / வணிக தொடர்பு / அலுவலகம்}
> **தொனி:** {அன்பான / மரியாதையான / நகைச்சுவையான / ஆன்மீகமான}
>
> **வழிகாட்டுதல்கள்:**
> - வார்த்தைகளை மீண்டும் மீண்டும் பயன்படுத்தாதே
> - 3 வேறுபட்ட பதிப்புகள் தா (குறுகிய / நடுத்தரம் / விரிவான)
> - Emoji சேர்க்கலாம் — ஆனால் அளவோடு

**பயன்பாடு:** Forward ஆகும் generic செய்திகளிலிருந்து வேறுபட்ட, தனிப்பட்ட வாழ்த்துகள்.

### 7️⃣ WhatsApp Business வரவேற்பு

> [!PROMPT]
> WhatsApp Business-ல் புதிய வாடிக்கையாளர் message அனுப்பும்போது தோன்றும் தன்னிச்சை வரவேற்பு (Welcome Message) எழுது.
>
> **வணிக விவரங்கள்:**
> - வணிக வகை: {கடை / உணவகம் / சேலை / பள்ளி / மருத்துவமனை / தொழில்நுட்ப சேவை / வீட்டு சேவை}
> - பெயர்: {வணிகத்தின் பெயர்}
> - முக்கிய சேவைகள்: {என்ன கொடுக்கிறீர்கள்}
> - பணி நேரம்: {எத்தனை மணிக்கு கிடைப்பீர்கள்}
>
> **சேர்க்க வேண்டியவை:**
> - அன்பான வரவேற்பு
> - என்ன தேவை என்று கேட்பது
> - பணி நேரம் & பதில் தாமதம் குறித்த எதிர்பார்ப்பு
> - விரைவு மெனு (Quick options: ஆர்டர் / விலை / இடம் / பேசுவது)
>
> 100 வார்த்தைகளுக்கு உட்பட்டு எழுது.

**பயன்பாடு:** WhatsApp Business → Settings → Messaging Tools → Welcome Message.

### 8️⃣ தயாரிப்பு விளக்கம்

> [!PROMPT]
> WhatsApp Catalog-ல் ஒரு பொருளுக்கான விளக்கம் எழுது.
>
> **பொருள் விவரங்கள்:**
> - பொருளின் பெயர்: {பெயர்}
> - வகை: {உணவு / ஆடை / மின்னணு சாதனம் / கைவினைப் பொருள் / சேவை}
> - முக்கிய சிறப்புகள்: {3-5 புள்ளிகள்}
> - விலை: {தேவைப்பட்டால் குறிப்பிடு}
> - இலக்கு வாடிக்கையாளர்: {யார்}
>
> **வடிவம்:**
> - முதல் வரி: கவரும் தலைப்பு
> - 3-4 bullet புள்ளிகளில் சிறப்புகள்
> - கடைசியில் CTA (ஆர்டர் செய்ய / விலை கேட்க / பார்க்க வர)
>
> 80 வார்த்தைகளுக்கு உட்பட்டு எழுது.

**பயன்பாடு:** WhatsApp Business Catalog-ல் பொருட்களை பட்டியலிட.

### 9️⃣ ஆர்டர் உறுதிப்படுத்தல்

> [!PROMPT]
> வாடிக்கையாளர் ஆர்டர் செய்தபின் WhatsApp-ல் அனுப்பும் உறுதிப்படுத்தல் (Confirmation) செய்தி எழுது.
>
> **விவரங்கள்:**
> - வணிக வகை: {உணவகம் / ஆடை / மின்னணு / வீட்டு சேவை / டிக்கெட்}
> - ஆர்டர் விவரங்கள்: {பொருள், அளவு, மொத்தம்}
> - டெலிவரி நேரம்: {எத்தனை நேரத்தில்}
> - கட்டணம்: {முன்பணம் செலுத்தினரா / வரும்போது கொடுப்பரா}
