### 1️⃣ தனிப்பட்ட பதிவு

> [!PROMPT]
> Facebook-ல் ஒரு தனிப்பட்ட பதிவுக்கான உரை எழுது.
>
> **பதிவு வகை:** {கருத்து பகிர்வு / நிகழ்வு / இடம் / உணர்வு / சாதனை / கேள்வி}
> **கருத்து:** {என்ன சொல்ல விரும்புகிறீர்கள்}
> **யாரைப் பார்க்க வேண்டும்:** {நண்பர்கள் மட்டும் / அனைவரும் / குறிப்பிட்ட குழு}
> **தொனி:** {அன்பான / தீவிர / நகைச்சுவை / ஊக்கம் / கோபம் > நேர்மறை}
>
> **வழிகாட்டுதல்கள்:**
> - Facebook-ல் Twitter / Instagram-ஐ விட நீண்ட பதிவுகள் நன்றாக வேலை செய்யும்
> - கமெண்ட் / Share தூண்டும் கேள்வி அல்லது CTA கடைசியில் சேர்
> - Emoji பயன்படுத்தலாம் — அளவோடு
> - 3 பதிப்புகள் தா: குறுகிய (50 வார்த்தை) / நடுத்தரம் (150 வார்த்தை) / விரிவான (300 வார்த்தை)

**பயன்பாடு:** தனிப்பட்ட கருத்துகள், அனுபவங்கள், மகிழ்ச்சி பகிர்வுகளுக்கு.

### 2️⃣ வணிக பக்கம் (Page) பதிவு

> [!PROMPT]
> Facebook Business Page-க்கான பதிவு எழுது.
>
> **வணிக விவரம்:**
> - வணிக வகை: {கடை / உணவகம் / சேவை / தொழில்நுட்பம் / கல்வி}
> - பதிவு நோக்கம்: {விற்பனை / விழிப்புணர்வு / நன்றி / தகவல் / சிறப்பு சலுகை}
> - கருத்து: {என்ன சொல்கிறீர்கள்}
>
> **கட்டமைப்பு:**
> - கவரும் தொடக்கம் (கேள்வி / பலன் / அதிர்ச்சி)
> - முக்கிய தகவல் (2-3 வாக்கியம்)
> - தெளிவான CTA (என்ன செய்ய வேண்டும் — ஒரே ஒரு action)
>
> 3 பதிப்புகள் தா. Image-உடன் பயன்படுத்தினால் Image Caption சேர்.

**பயன்பாடு:** Facebook Page-ல் வாடிக்கையாளர்களை ஈர்க்க.

> **அறிவிப்பு வகை:** {கூட்டம் / மாற்றம் / புதிய விதிமுறை / சிறப்பு நிகழ்வு / தகவல்}

> **வழிகாட்டுதல்கள்:**

**பயன்பாடு:** Pinned Post ஆக வை — குழு உறுப்பினர்கள் எல்லோரும் காண.

>

> **முக்கிய சவால்கள்:** {Spam / விளம்பரம் / அரசியல் சண்டை / தவறான தகவல் / வெளிப்பட்ட பொருள்}
> **உறுப்பினர் எண்ணிக்கை:** {சிறிய / நடுத்தரம் / பெரியது}
>
> **வடிவம்:**
> - 5-8 விதிமுறைகள் மட்டும் (Facebook Rules section format-ல்)
> - ஒவ்வொரு விதியும்: தலைப்பு + ஒரு வரி விளக்கம்
> - கண்ணியமான, நேரடியான மொழி
> - மீறினால் என்ன நடக்கும் — கடைசியில்

**பயன்பாடு:** Group Settings → Rules-ல் சேர்க்க.
