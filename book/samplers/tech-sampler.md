## 1. செயல்பாடு / கிளாஸ் உருவாக்கம்

> [!PROMPT]
> நீ ஒரு மூத்த {நிரலாக்க மொழி — Python / Java / JavaScript / TypeScript} டெவலப்பர்.
> கீழ்க்கண்ட தேவைக்கு ஏற்ப ஒரு {செயல்பாடு / கிளாஸ்} எழுதுக:
>
> **தேவை:** {என்ன செய்ய வேண்டும் — விரிவாக}
> **உள்ளீடு:** {வகை + விளக்கம்}
> **வெளியீடு:** {வகை + விளக்கம்}
>
> **கட்டுப்பாடுகள்:**
>
> - SOLID கொள்கைகள் பின்பற்றுக
> - பிழை கையாளுதல் கட்டாயம்
> - வகை குறிப்புகள் சேர்க்கவும்
> - தமிழில் குறிப்புகள் + ஆங்கிலத்தில் docstring
> - நேர சிக்கலளவு குறிப்பிடுக

**பயன்பாடு:** தர உயர்ந்த, ஆவணப்படுத்தப்பட்ட குறியீடு விரைவாக எழுத.

## 2. API இறுதிப்புள்ளி வடிவமைப்பு

> [!PROMPT]
> '{வணிகத் தேவை — எ.கா., பயனர் பதிவு / பொருள் தேடல் / கட்டணம் செலுத்துதல்}' க்கான ஒரு RESTful API-யை வடிவமைக்கவும்:
>
> **ஒவ்வொரு இறுதிப்புள்ளிக்கும்:**
>
> | HTTP Method | Path | விளக்கம் | Request Body | Response | Status Codes |
> |-------------|------|---------|-------------|----------|-------------|
>
> **கூடுதல் தேவைகள்:**
>
> - அங்கீகாரம்: {JWT / OAuth / API Key}
> - வரம்பு கட்டுப்பாடு: ✅ / ❌
> - பதிப்பு: /api/v1/---
> - OpenAPI (Swagger) ஆவணம்: ✅
>
> **Response வடிவம்:**
>
> ```json
> { "status": "success/error", "data": {}, "message": "தமிழில் செய்தி", "timestamp": "" }
> ```

**பயன்பாடு:** தமிழ் சேவைகளுக்கான நிலையான RESTful API வடிவமைக்க.
