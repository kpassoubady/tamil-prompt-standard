## 1. WhatsApp செய்தி வடிவமைப்பு

> [!PROMPT]
> நீ ஒரு தமிழ் மொழி ஆலோசகர். கீழ்க்கண்ட சூழ்நிலைக்கு ஒரு WhatsApp செய்தி எழுது.
>
> **சூழ்நிலை விவரங்கள்:**
> - செய்தி வகை: {உதவி கேட்பது / நன்றி தெரிவிப்பது / மன்னிப்பு கேட்பது / தகவல் அனுப்புவது / ஆலோசனை கேட்பது}
> - யாருக்கு: {நண்பர் / மூத்தவர் / ஆசிரியர் / அலுவலக சக்கிராதி / குடும்பத்தினர்}
> - பொருள்: {செய்தியின் முக்கிய கருத்து}
> - தொனி: {அன்பான / மரியாதையான / நேரடியான / சற்று முறையான}
> - நீளம்: {3-4 வரி / 1 பத்தி / விரிவான}
>
> **வழிகாட்டுதல்கள்:**
> - WhatsApp formatting பயன்படுத்து (*bold*, _italic_ தேவைப்பட்டால்)
> - Emoji சேர் (சேர்க்கவேண்டாம் என்றால் குறிப்பிடு)
> - இயற்கையான தமிழில் எழுது — அகராதி தமிழ் வேண்டாம்

**பயன்பாடு:** அன்றாட WhatsApp செய்திகளை சரியான தொனியில் அனுப்ப.

## 2. YouTube வீடியோ தலைப்பு

> [!PROMPT]
> நீ ஒரு தமிழ் YouTube SEO நிபுணர். கீழ்க்கண்ட வீடியோவுக்கு தேடல் நோக்கில் சிறந்த தலைப்புகளை உருவாக்கு.
>
> **வீடியோ பற்றி:**
> - பொருள்: {வீடியோவின் முக்கிய கருத்து}
> - சேனல் வகை: {கல்வி / சமையல் / தொழில்நுட்பம் / நகைச்சுவை / செய்தி / தனிப்பட்ட / கலை}
> - இலக்கு பார்வையாளர்: {வயது, ஆர்வம், அறிவு நிலை}
> - மொழி கலவை: {தமிழ் மட்டும் / Tanglish / தமிழ் + ஆங்கில Terms}
>
> **10 தலைப்புகள் தா — வேறு வேறு வகைகளில்:**
>
> | # | தலைப்பு | வகை | ஏன் வேலை செய்யும் |
> |---|---------|-----|-----------------|
> | 1 | | கேள்வி வடிவம் | |
> | 2 | | எண் பட்டியல் | |
> | 3 | | "இப்படி செய்யாதே" | |
> | 4 | | "நான் கற்றுக்கொண்டேன்" | |
> | 5 | | அதிர்ச்சி / ஆச்சரியம் | |
> | 6 | | "முதல்முறை" | |
> | 7 | | SEO-direct | |
> | 8 | | உணர்வுப்பூர்வம் | |
> | 9 | | நேர அழுத்தம் | |
> | 10 | | உள்ளூர் / Tamil-specific | |
>
> ஒவ்வொரு தலைப்பும் 60 எழுத்துகளுக்கு உட்பட்டு இருக்கட்டும்.

**பயன்பாடு:** வீடியோ upload செய்வதற்கு முன் சிறந்த தலைப்பு தேர்வு செய்ய.
