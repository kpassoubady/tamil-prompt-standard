## 1. தொழில்முறை ரெசுமே எழுதுதல்

```prompt
நீ ஒரு தொழில்முறை ரெசுமே எழுத்தாளர்.
என்னுடைய விவரங்களை வைத்து ஒரு ATS-friendly ரெசுமே தயார் செய்.

**என்னுடைய தகவல்கள்:**
- பெயர்: {பெயர்}
- கல்வி தகுதி: {பட்டம், கல்லூரி, ஆண்டு}
- அனுபவம்: {ஆண்டுகள் / Fresher}
- தொழில் இலக்கு: {வேலை பட்டம்}
- முக்கிய திறன்கள்: {திறன்கள் பட்டியல்}
- இதுவரை செய்த வேலைகள்: {நிறுவனம், பாத்திரம், ஆண்டுகள்}
- கூடுதல் சாதனைகள்: {சான்றிதழ்கள், திட்டங்கள்}

**ரெசுமே வடிவம்:**
1. **தொடர்பு தகவல்:** மேலே வலது
2. **தொழில் சுருக்கம்:** 3 வரிகள் — இலக்கு நோக்கி
3. **திறன்கள்:** Technical + Soft Skills
4. **அனுபவம்:** STAR முறையில் — சாதனைகள் முன்னிலைப்படுத்தி
5. **கல்வி:** GPA (4.0+ மட்டும்)
6. **திட்டங்கள்:** 2-3 முக்கியமானவை

**கட்டுப்பாடுகள்:** ஒரு பக்கம் மட்டும், எளிய வடிவம், வலிமையான வினைச்சொற்கள்
```

**பயன்பாடு:** வேலை விண்ணப்பத்திற்கான தொழில்முறை ரெசுமே உருவாக்க.

## 2. நேர்காணல் தயாரிப்பு

```prompt
நீ ஒரு மூத்த HR நிபுணர் மற்றும் நேர்காணல் பயிற்சியாளர்.
{நிறுவனம்} நிறுவனத்தில் {வேலை பட்டம்} பதவிக்கான நேர்காணலுக்கு என்னை தயார் செய்.

**என்னுடைய விவரம்:**
- பதவி விண்ணப்பம்: {Job Title}
- நிறுவனம்: {Company Name}
- என் அனுபவம்: {ஆண்டுகள் / Fresher}
- வலிமை: {3 முக்கிய திறன்கள்}
- பலவீனம்: {நான் மேம்படுத்த விரும்புவது}

**தயாரிப்பு வேண்டியவை:**
1. **பொதுவான கேள்விகள்:** 5 கேள்வி + பரிந்துரைக்கப்பட்ட பதில்கள்
   - "உங்களை பற்றி சொல்லுங்கள்"
   - "உங்கள் வலிமைகள் / பலவீனங்கள்?"
   - "5 வருடங்களில் நீங்கள் எங்கே இருப்பீர்கள்?"

2. **நடத்தை கேள்விகள் — STAR முறை:** 3 கேள்வி + STAR பதில் வடிவம்

3. **நிறுவனம் சார்ந்த கேள்விகள்:** {நிறுவனம்} பற்றி 5 முக்கிய தகவல்கள்

4. **என்னிடம் கேட்க வேண்டிய கேள்விகள்:** 3 ஆழமான கேள்விகள்

5. **கடைசி நிமிட குறிப்புகள்:** 5 புள்ளிகள்
```

**பயன்பாடு:** வேலை நேர்காணலுக்கு முழுமையான தயாரிப்பு செய்ய.
